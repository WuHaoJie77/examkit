管理会计 第四章 本量利分析 浓缩速记卡

公式密集型计算章 | 55+题 | 预计用时55分钟

💡 费曼类比：本量利分析就是算一笔账——卖多少件才不亏（保本点），想赚多少得卖多少（保利点），现在比保本点多卖了几个（安全边际）。全部围绕一条公式展开：利润 = 销量×(单价-单位变动成本) - 固定成本。剩下的全是这条公式的变形。

一、核心公式库（必背！）

边际贡献（贡献边际）

公式 说明
单位边际贡献 = 单价 - 单位变动成本 = P - V
边际贡献总额 = 销售收入 - 变动成本总额 = (P-V)×Q
边际贡献率 = (P-V)/P = 1 - 变动成本率
变动成本率 = V/P = 1 - 边际贡献率 边际贡献率 + 变动成本率 = 1

保本点（盈亏临界点）

实物量 金额
保本量 = F / (P-V) = 固定成本÷单位边际贡献 保本额 = F / 边际贡献率

安全边际

公式 关系
安全边际量 = 实际销量 - 保本量 越大越安全
安全边际额 = 实际销售额 - 保本额
安全边际率 = 安全边际量/实际销量 + 保本作业率 = 1
保本作业率 = 保本量/实际销量
利润 = 安全边际量 × 单位边际贡献 最快捷算法！
利润 = 安全边际额 × 边际贡献率

保利点

| 保利量 = (F + 目标利润) / (P-V) | | 保净利量 = (F + 目标净利润/(1-税率)) / (P-V) |

敏感系数

| 敏感系数 = 利润变动% / 因素变动% | | 单价敏感系数 > 销量敏感系数 > 固定成本敏感系数 |

二、公式关系图

销售收入 - 变动成本 = 边际贡献
边际贡献 - 固定成本 = 利润

边际贡献率 + 变动成本率 = 1
安全边际率 + 保本作业率 = 1

三、典型计算精讲

例题1：保本+保利基础题

单价6元，单位变动成本4元，固定成本800元，正常销售额3,000元（500件）。

  • 单位边际贡献 = 6-4 = 2元
  • 边际贡献率 = 2/6 = 33.33%
  • 保本量 = 800/2 = 400件；保本额 = 800/33.33% = 2,400元
  • 安全边际量 = 500-400=100件；安全边际率 = 100/500=20%
  • 保本作业率 = 1-20% = 80%
  • 利润 = 100×2 = 200元（= 500×(6-4)-800=200 ✓）

例题2：边际贡献率反推单价

直接材料4+直接人工3+变动制造费2+变动销售管理费3=单位变动成本12元。边际贡献率40%，求单价。

解：

边际贡献率 = (P-12)/P = 0.4 → P-12 = 0.4P → 0.6P = 12 → P = 20元

例题3：综合加权边际贡献率

甲销售额80,000元，变动成本60,000元（边际贡献率25%）；乙销售额120,000元，变动成本60,000元（边际贡献率50%）。总固定成本30,000元。

  • 总销售额 = 200,000元
  • 甲销售比重=80,000/200,000=40%，乙=60%
  • 加权边际贡献率 = 25%×40% + 50%×60% = 10%+30% = 40%
  • 综合保本额 = 30,000/40% = 75,000元
  • 甲保本额 = 75,000×40% = 30,000元；乙保本额 = 75,000×60% = 45,000元
  • 安全边际额 = 200,000-75,000 = 125,000元
  • 预计利润 = 125,000×40% = 50,000元

例题4：敏感系数

已知利润对单价的敏感系数为2。确保不亏损，单价最大下降幅度？

解：

敏感系数=利润变动%/单价变动% → 利润下降100%（由盈转亏）→ 100%/2=50% 单价最大下降50%

例题5：保净利

单价20元，单位变动成本15元，固定成本10,000元，目标净利润13,400元，所得税率33%。销售量？

解：

目标税前利润 = 13,400/(1-33%) = 20,000元 保利量 = (10,000+20,000)/(20-15) = 6,000件

四、快速判断题汇总

动作 保本点 安全边际
单价↑ ↓ ↑
单位变动成本↑ ↑ ↓
固定成本↑ ↑ ↓
销量↑ 不变 ↑
边际贡献率↑ ↓ ↑

关键理解：销量不影响保本点（保本点由单价、变动成本、固定成本决定）。

计算题（5题）

题1：单价50元，单位变动成本30元，固定成本40,000元，正常销量3,000件。求保本量、安全边际率、利润。

题4：甲边际贡献率25%（销售额占40%），乙边际贡献率50%（销售额占60%）。固定成本30,000元。求综合保本额和各产品保本额。

题5：单价200元，目标销量3,500件，固定成本100,000元，目标利润600,000元。单位变动成本应控制在多少？

六、答案与解析

选择题答案

题号 答案 关键推导
1 B 保本量=F/(P-V)=F/单位边际贡献
2 B 边际贡献率+变动成本率=1，互为补数
3 C 边际贡献=200,000×65%=130,000；利润=130,000-F=100,000→F=30,000
4 B 安全边际率+保本作业率=1
5 B 增加销量→安全边际↑，但保本点不变（销量不影响保本点）
6 B 保本点越高=盈亏线越高→相同销量下利润越少
7 A 100%/2=50%
8 B 变动成本↑→边际贡献↓→保本点↑→安全边际↓
9 C 加权边际贡献率=Σ(各产品边际贡献率×销售比重)
10 B 同比例上升：P↑x%, V↑x%→(P-V)变化比例>(P-V)原值→需判断。实际上(1+x)P-(1+x)V=(1+x)(P-V)，而F不变→保本量=F/[(1+x)(P-V)]→保本量下降...等等，(1+x)(P-V)变大→保本量下降！所以答案是C。

等等第10题需要再算：P新=P(1+x), V新=V(1+x), 单位边际贡献新=(P-V)(1+x)。因为P-V>0, 且(1+x)>1, 所以新边际贡献>原边际贡献→保本量=F/新边际贡献<原保本量→下降(C)。

计算题答案

题1：边际贡献=50-30=20；保本量=40,000/20=2,000件；安全边际量=3,000-2,000=1,000件；安全边际率=1,000/3,000=33.33%；利润=1,000×20=20,000元。

题2：保本量=800/(6-4)=400件；实际量=3,000/6=500件；保本作业率=400/500=80%。

题3：边际贡献率=1-40%=60%。保利额=(1,000,000+200,000)/60%=2,000,000元。单价=2,000,000/20,000=100元。

题4：加权边际贡献率=25%×40%+50%×60%=40%。综合保本额=30,000/40%=75,000元。甲保本额=75,000×40%=30,000元；乙保本额=75,000×60%=45,000元。

题5：设单位变动成本=V。3,500×(200-V)-100,000=600,000 → 3,500(200-V)=700,000 → 200-V=200 → V=0？ 验算有误？

重算：3,500×(200-V)-100,000=600,000 → 700,000-3,500V-100,000=600,000 → 600,000-3,500V=600,000 → V=0→数据可能有问题，目标利润太大以致于要零变动成本。此题为原题第28题，2000×3,500=7,000,000收入，固定100,000+利润600,000=700,000需要边际贡献→单位边际贡献=700,000/3,500=200→V=2,000-200=1,800元/件。原题单价是2000元不是200元！→ V=2,000-200=1,800元/件。

七、防坑预警

❌ 学生常犯 ✅ 正确做法
提高销量会降低保本点 销量不影响保本点！保本点由P/V/F决定
保净利直接用(F+净利润)/(P-V) 净利润要先÷(1-税率)转成税前利润
安全边际率+边际贡献率=1 安全边际率+保本作业率=1
加权边际贡献率用产量比重 用销售额比重，不是产量比重
敏感系数=因素变动%/利润变动% 敏感系数 = 利润变动% / 因素变动%
