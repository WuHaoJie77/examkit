管理会计 第七章 全面预算 浓缩速记卡

预算编制流程 | 20题 | 预计用时25分钟

💡 费曼类比：全面预算就像排年度家庭开支——先算明年大概赚多少（销售预算），再算要买多少菜（生产预算→材料预算），请几个人帮忙（人工预算），年底剩多少钱（现金预算），最后出一张明年预计的财务报表。

一、预算体系层次（从起点到终点）

销售预算（起点）
  → 生产预算（生产量=销量+期末-期初）
    → 直接材料预算（采购量=需用量+期末存量-期初存量）
    → 直接人工预算（生产量×工时×工资率）
    → 制造费用预算（变动+固定-折旧=现金支出）
  → 现金预算
  → 预计财务报表（终点：预计利润表+预计资产负债表）
预算类型 内容
业务预算 销售/生产/材料/人工/制造费/期间费预算
财务预算 现金预算、预计财务报表
专门决策预算 资本支出等一次性预算

二、核心计算公式

生产预算

预计生产量 = 预计销售量 + 预计期末存货 - 预计期初存货

例题：期初50件，期末40件，销量250件。生产量=250+40-50=240件。

材料采购预算

预计采购量 = 生产需用量 + 预计期末材料存量 - 预计期初材料存量

现金收支

预计现金收入 = 当期销售×当期收款% + 上期销售×本期收款%
预计现金支出 = 当期采购×当期付款% + 上期采购×本期付款%

例题：四季度采购2,500kg×10元+期末300-期初500=2,300kg→23,000元。当期付40%=9,200；下期付60%=13,800元（=年末应付账款）。

应收账款：四季度销售40,000元，当季收60%=24,000，下季收40%=16,000元（年末应收账款）。

弹性预算 vs 静态预算

静态预算 弹性预算
编制基础 单一预计业务量 多种业务量水平
调整 不调整 按实际产量调整
适用 业务量波动小时 业务量波动大时
本质 "一个数"管到底 "按实际来"动态配

三、快速判断

判断 答案
其他预算的起点 销售预算
全面预算终点 预计财务报表
现金支出需剔除的项目 折旧费（不付现金）
不需另计现金收支直接参加现金预算 人工预算
反映预算期盈利能力 预计利润表
克服固定预算缺点 弹性预算
零基预算特点 每项支出从零开始论证，不以历史数据为基础
增量预算特点 在上年基础上调整增减

四、⚠️ 防坑预警

❌ 学生常犯 ✅ 正确做法 为什么
生产预算是全面预算的起点 销售预算是起点——所有其他预算都从销售预算推导。顺序：销售→生产→材料→人工→制造费用→现金→报表 没有销售预测，生产多少、买多少材料都无法确定。销售预算是整个预算体系的"发动机"
预算 = 预测，一回事 预算≠预测。预测是对未来结果的估计（"明年大概卖多少"）。预算是目标+资源分配方案（"我们计划明年卖多少，并据此分配资源"） 预测是"猜"，预算是"定"。混淆的话会把预算当成"随便改的估算"，失去管控意义
零基预算就是在上年基础上调整 零基预算每项从零开始论证，每笔支出都要重新证明其必要性。增量预算才是以上年为基础调整 零基=归零重来，增量=上年×系数。二者本质不同——零基更彻底但费时，增量省事但可能积累冗余
弹性预算和静态预算只是名字不同 弹性预算按实际产量调整各项预算数，静态预算不调。产量变了：静态预算还在用原来的数，弹性预算重新算 考试中给"实际产量"的通常是弹性预算题——让你对比实际成本与弹性预算数（而非原始静态预算数）

计算题（3题）

题1：1-4季度销量：1,000/800/900/850件。每件用A材料2kg。季末产成品存货=下季销量10%，季末材料存量=下季生产需要量20%。求二季度材料采购量。

题2：四季度初材料500kg，生产需用2,500kg，期末存量300kg，单价10元。40%当期付，60%下期付。年末应付账款？

题3：每季销售中本季收60%，下季收40%。四季度销售40,000元。年末应收账款？

六、答案与解析

选择题答案

题号 答案 思路 推导 坑点
1 B 预算编制起点 销售预算决定生产量→生产决定材料/人工/费用 经常有选项"生产预算"——但生产预算是第二个不是第一个
2 B 生产量公式 生产量=销量+期末-期初=250+40-50=240件 是"+期末-期初"，不是"-期末+期初"，符号别搞反
3 C 预算终点 所有预算最终汇入预计利润表和预计资产负债表 现金预算是中间站，不是终点
4 B 现金预算内容 产销量是实物量信息，现金预算只反映金额和现金流 现金预算=钱的进出，不管生产了几件
5 C 预算编制顺序 销售→生产→材料。材料预算以生产预算为基础（知道生产多少才知用料多少） 不是直接以销售预算为基础——中间隔了生产预算
6 D 现金支出剔除项 折旧=不付现费用→计算现金支出时必须剔除 管理人员工资要付现金，不能剔除
7 A 应收账款计算 40,000×40%=16,000（下季才收的部分=年末应收） 当季收60%、下季收40%→下季收的40%就是期末应收
8 D 预算分类 现金预算=资金筹划→财务预算 不要被"现金"误导成业务预算——涉及投融资和资金调度的都是财务预算
9 D 生产预算边界 生产预算=生产量+期初期末存货+销量。购货量属于材料采购预算 生产预算只管"生产多少"，不管"买多少材料"
10 B 弹性预算定义 弹性预算按一系列业务量水平编制，适应业务量变化 A是错的——弹性预算不仅用于间接费用，也可用于直接成本

计算题答案

题1：

  • 思路：生产预算+材料采购预算联动计算。核心链路：销量→产成品存货→生产量→材料需用量→材料存量→材料采购量。
  • 推导： ① 二季度期末产成品 = 三季度销量900×10% = 90件 ② 二季度期初产成品 = 一季度期末 = 二季度销量800×10% = 80件 ③ 二季度生产量 = 800 + 90 - 80 = 810件 ④ 二季度生产需用材料 = 810×2 = 1,620kg ⑤ 三季度生产量：三季度销量900+期末850×10%(=85)-期初90 = 895件 → 需料1,790kg ⑥ 二季度末材料存量 = 1,790×20% = 358kg ⑦ 二季度初材料存量 = 1,620×20% = 324kg ⑧ 二季度材料采购量 = 1,620+358-324 = 1,654kg
  • 坑点：季末材料存量按下季度生产需用量的20%，不是下季度采购量。很多人直接拿季度采购量×20%，那就循环引用了。

题2：

  • 思路：先算采购量（需用量+期末-期初），再算采购金额，再按付款比例求应付账款。
  • 推导：采购量 = 2,500+300-500 = 2,300kg；采购金额 = 2,300×10 = 23,000元；年末应付账款 = 23,000×60% = 13,800元（下期付的部分）。
  • 坑点：应付账款=本期采购中下期才付的部分，不是"期初材料存量的价值"。另外折旧费不在现金预算中——但这里不涉及折旧。

题3：

  • 思路：应收账款=本期销售中下期才收回的部分=销售额×(1-本期收款比例)。
  • 推导：年末应收账款 = 40,000×(1-60%) = 40,000×40% = 16,000元。
  • 坑点：当季收60%是"本季收到现金"的部分，下季收40%才是"挂账"部分=应收。方向不要反。
