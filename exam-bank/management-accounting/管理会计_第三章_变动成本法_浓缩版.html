管理会计 第三章 变动成本法 浓缩速记卡

⚠️ 全书计算核心！成本性态分析 + 变动成本法 | 40+题 | 预计用时60分钟

💡 费曼类比：成本性态分析就像给你的钱分类——有些钱不管干不干活都要花（房租=固定），有些多干多花少干少花（材料费=变动），还有些带起步价的（电话月租58元+超出的每分钟0.15元=混合）。变动成本法vs完全成本法的区别就像算饭店利润——变动成本法只算"这盘菜用了多少食材"，固定成本（房租）一次扣光；完全成本法则把房租也摊进每盘菜里。

一、成本按性态分类

类型 特征 总额 单位额 举例
固定成本 不随业务量变 不变 反比例变动（量↑→单位↓） 折旧、租金、管理人员工资
变动成本 随业务量正比变 正比例变动 不变 直接材料、计件工资、按产量法折旧
混合成本 半变动 y=a+bx — 电话月租+超时费、机器维护费

判断："在相关范围内，单位固定成本不变" → ❌ 错！单位固定成本反比例变动。总额不变，单位额变。

二、固定成本两种类型（高频考点！）

约束性固定成本 酌量性固定成本
能否短期改变 ❌ 不能 ✅ 能（管理层短期决策可调整）
本质 维持经营必须的 管理层选择的
典型例子 厂房折旧、保险费、财产税、管理人员薪金 广告费、职工培训费、研发费、差旅费

约束性=不动不行（折旧/保险/税）；酌量性=可多可少（广告/培训/研发）

例题："在不改变生产经营能力的前提下能降低其总额的固定成本是？" → 酌量性固定成本（约束性的降不了）

三、混合成本分解方法

方法对比

方法 精度 核心
高低点法 最低（只用两点） 选最高业务量和最低业务量的点
散布图法 中等 目测画线
一元直线回归法 最精确 最小二乘法

高低点法流水线

Step 1：选高点=业务量最高的月份（不是成本最高！） Step 2：b（单位变动成本）=（高成本-低成本）/（高业务量-低业务量） Step 3：a（固定成本）= 高成本 - b×高业务量（或用低成本） Step 4：写出公式 y = a + bx

例题：维修费数据，最高业务量1,400千小时/93,000元，最低125千小时/95,000元。

等等——最高业务量是1,400，对应成本93,000；最低业务量是125，对应成本95,000。最低业务量的成本反而更高？ 这说明高低点法的局限：只看两个极端点可能被异常值干扰。

正确做法：b = (93,000-95,000)/(1,400-125) = -2,000/1,275 ≈ -1.57（结果为负说明高低点法在此数据上失效，应改用回归法） 坑：高低点按业务量选点，不是按成本选。即使最低业务量的成本更高，也得用那组数据。

四、变动成本法 vs 完全成本法（★★★ 全书最重要对比）

产品成本构成

项目 变动成本法 完全成本法
直接材料 ✅ 产品成本 ✅ 产品成本
直接人工 ✅ 产品成本 ✅ 产品成本
变动性制造费用 ✅ 产品成本 ✅ 产品成本
固定性制造费用 ❌ 期间成本（当期全扣） ✅ 产品成本（摊入存货）
销售费用+管理费用 期间成本 期间成本

变动成本法下产品成本 = 直接材料 + 直接人工 + 变动性制造费用（也叫"变动生产成本"）

利润差异公式（必背！）

完全成本法利润 - 变动成本法利润 = 期末存货吸收的固定制造费用 - 期初存货释放的固定制造费用

三种情形： | 产销关系 | 利润比较 | |---------|---------| | 产量 = 销量（产销平衡）| 两种方法利润相等 | | 产量 > 销量（期末存货增加）| 完全成本法利润 > 变动成本法利润 | | 产量 < 销量（期末存货减少）| 完全成本法利润 < 变动成本法利润 |

判断："只要各年销量相同，变动成本法下各年税前利润就相同" → ✅ 对！变动成本法下利润只跟销量挂钩，与产量无关。

五、计算精讲

例题1：利润差异计算

某公司期初存货50件，期末40件。完全成本法下期初单位成本40元，期末单位成本50元。变动成本法下单位成本30元。完全成本法比变动成本法利润多/少？

解：

固定制造费用单位额 = 完全成本-变动成本 期初：40-30=10元/件；期末：50-30=20元/件 期初释放 = 50×10=500元；期末吸收 = 40×20=800元 差异 = 800-500 = +300元 完全成本法利润比变动成本法多300元（存货净吸收300元固定制造费用）

例题2：变动成本法利润反推完全成本法

变动成本法利润4,000元。产量2,000件，销量1,000件，期初0，固定制造费用总额2,000元。完全成本法利润？

解：

单位固定制造费用 = 2,000÷2,000 = 1元/件 期末存货 = 2,000-1,000 = 1,000件 期末吸收固定费 = 1,000×1 = 1,000元（期初释放=0） 完全成本法利润 = 4,000 + 1,000 = 5,000元

例题3：高低点法完整计算

月份 业务量(千h) 维修费(元)
3月 125 95,000
8月 700 72,000
11月 1,400 93,000

高点=1,400(11月)，低点=125(3月) b = (93,000-95,000)/(1,400-125) = -1.5686 a = 93,000 - (-1.5686×1,400) = 95,196 公式：y = 95,196 + (-1.57)x → 不合理（b为负说明高低点法不适用，应改回归法）

改用实际合理数据计算（如用1,400和700）： b = (93,000-72,000)/(1,400-700) = 30 元/千时 a = 93,000 - 30×1,400 = 51,000 y = 51,000 + 30x

计划1,800千时：51,000 + 30×1,800 = 105,000元

计算题（5题）

题1：维修费数据。高点：1,200h/90,000元，低点：700h/72,000元。用高低点法求成本公式，并预测1,500h的维修费。

题2：期初存货100件（完全成本50元/件，变动成本35元/件），期末存货80件（完全成本55元/件，变动成本35元/件）。求完全成本法与变动成本法的利润差异。

题3：变动成本法利润10,000元。产量3,000件，销量2,500件，期初存货200件（含固定制造费用5元/件），固定制造费用总额15,000元。求完全成本法利润（先进先出）。

题4：分别用变动成本法和完全成本法写出产品成本的构成项目。

题5：中原公司，产量每年6,000件。第一年销量6,000件，第二年5,000件，第三年7,000件。单价25元，变动生产成本12元/件，固定制造费用18,000元/年。变动销售管理费=销售收入×4%，固定销售管理费12,000元/年。求各年两种方法下的税前利润并解释差异。

七、答案与解析

选择题答案（简要）

题号 答案 关键推导
1 D 成本性态=按与业务量的关系分类
2 B 单位固定成本=总额÷业务量，业务量↑→单位↓（反比）
3 B 酌量性=管理层可调整；约束性=必须发生
4 C 厂房折旧=经营必须=约束性。A/B/D都是酌量性
5 B 按业务量选点，不是按成本选
6 C 回归法=最小二乘法=最精确
7 D 变动成本法=料+工+变动制造费。固定制造费=期间成本
8 B 固定制造费在变动成本法下=期间成本，当期全扣
9 B 产销平衡→期末存货=期初存货→吸收=释放→利润相等
10 B 产>销→存货增加→吸收固定费→完全成本法利润更大
11 A 变动成本法下利润仅与销量挂钩
12 B 58元包450分钟，超出部分才变动→延期变动成本
13 C 单位固定费=2,000÷2,000=1；期末存货1,000件吸收1,000元；4,000+1,000=5,000
14 A 正常时间固定（不随工时变），加班按时间→延期变动
15 C y=a+bx：a=固定总额，bx=变动总额

计算题答案

题1： b = (90,000-72,000)/(1,200-700) = 36元/h a = 90,000 - 36×1,200 = 46,800 y = 46,800 + 36x 1,500h：46,800 + 36×1,500 = 100,800元

题2： 期初释放 = 100×(50-35) = 1,500 期末吸收 = 80×(55-35) = 1,600 差异 = 1,600-1,500 = +100元 完全成本法利润比变动成本法多100元

题3： 本期单位固定制造费 = 15,000÷3,000 = 5元/件 期末存货 = 200+3,000-2,500 = 700件 先进先出：期末700件全是本期生产的→期末固定费=700×5=3,500 期初200件固定费=200×5=1,000 差异 = 3,500-1,000 = +2,500 完全成本法利润 = 10,000+2,500 = 12,500元

题4：变动成本法=直接材料+直接人工+变动性制造费用。完全成本法=直接材料+直接人工+变动性制造费用+固定性制造费用。

题5： 单位固定制造费 = 18,000÷6,000 = 3元/件 变动成本法利润（仅与销量有关）： - 第一年：6,000×(25-12) - 6,000×25×4% - 18,000 - 12,000 = 78,000-6,000-18,000-12,000 = 42,000元（销量6,000） - 第二年：5,000×13 - 5,000-18,000-12,000 = 65,000-5,000-30,000 = 30,000元（销量5,000） - 第三年：7,000×13 - 7,000-18,000-12,000 = 91,000-7,000-30,000 = 54,000元（销量7,000）

完全成本法利润： - 第一年：产销平衡→与变动成本法相同=42,000元 - 第二年：产6,000>销5,000，存货+1,000件→吸收3,000元 → 30,000+3,000=33,000元 - 第三年：产6,000<销7,000，存货-1,000件→释放3,000元 → 54,000-3,000=51,000元

差异原因：第二年产量>销量，固定制造费用3,000元被存货吸收（完全成本法利润更高）；第三年产量<销量，期初存货中的固定费释放（完全成本法利润更低）。

八、防坑预警

❌ 学生常犯 ✅ 正确做法
高低点法选成本最高的点 选业务量最高的点
变动成本法固定制造费进产品成本 固定制造费=期间成本（当期全扣）
产销平衡时利润仍有差异 产销平衡→利润相等
单位固定成本不变 单位固定成本反比例变动
约束性固定成本可以短期降低 约束性=不能短期改变
