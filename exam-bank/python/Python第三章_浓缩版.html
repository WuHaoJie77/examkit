Python 第三章 浓缩速记卡（print · input · eval · 缩进注释 · IPO）

一、print() 输出函数

🧠 费曼：print = 电脑张嘴说话。 你让电脑说"你好"，print("你好")。让电脑算个数再说出来，print(100+200)，它先算300再说。你说多个东西用逗号隔开，print("结果", 300)，它自动在中间加空格。sep控制怎么隔，end控制说完后加什么尾巴——默认是换行，改成end=""就不换行，下一句print的话可以接在后面。

1.1 核心用法

print("Hello")                    # 基本输出
print("a", "b", "c")              # 多对象输出，默认空格分隔  → a b c
print(100 + 200)                  # 输出表达式结果  → 300
print("结果=", 1+2)               # 混合输出  → 结果= 3

1.2 关键参数

参数 作用 默认值 示例
sep 多个对象之间的分隔符 空格 print(1,2,3,sep="-") → 1-2-3
end 输出结尾字符 换行 \n print("Hi", end="") → 不换行

1.3 易错判断题

说法 对错 真相
print只能输出字符串 ❌ 可以输出任何类型，自动转str
print(100+200) 输出 "100+200=300" ❌ 输出 300，没有引号和等号
多对象间默认用制表符分隔 ❌ 默认用空格，不是tab
print('a') 输出带引号的 'a' ❌ 输出 a，print自动去引号
print "hello" 在Python3合法 ❌ Python3必须加括号
print(Hello World) 正确 ❌ 字符串必须加引号

1.4 链式print不换行

print("1", end="")       # 输出1，不换行
print("1", end=",")      # 输出1,，不换行
print("1")               # 输出1，换行
# 最终：11,1

二、input() 输入函数

🧠 费曼：input = 电脑竖起耳朵听你说话。 你对着电脑说了一个数字86，input()听到的是"86"这两个字符——它不是数字，是穿了数字衣服的字符串！想让86变成真正的数字能拿来算，得叫eval()来翻译：eval(input())。"eval"就是翻译官，把"人话的86"变成"电脑能算的86"。

2.1 铁律：input() 永远返回字符串

x = input("请输入：")    # 用户输入什么都行
# x 的类型永远是 str，不管用户输入的是数字还是字母
用户输入 input()返回 类型
123 "123" str
3.14 "3.14" str
张三 "张三" str
空（直接回车） "" str

2.2 input 参数

  • 参数是提示字符串（可选，最多一个）
  • 参数只能是字符串，不能是数值/列表
  • 返回值是用户输入的内容，不是提示字符串
a = input("请输入你的名字：")   # "请输入你的名字："是提示
# 用户输入：张三
# a = "张三"，不是"请输入你的名字："

name = input()                  # 不带参数也行

2.3 input vs eval(input)

# 用户输入 86
a = input("输入：")        # a = "86" (字符串)
b = eval(input("输入："))  # b = 86 (整数)

三、eval() 评估函数（重点！）

3.1 功能

把字符串当成 Python 表达式执行，返回结果。

eval("123")          # 123 (int)
eval("3+5")          # 8
eval("100+200")      # 300
eval("2**3")         # 8
eval("'hello'")      # 'hello' (str)
eval("print('Hi')")  # 输出Hi，返回None
eval("len('abc')")   # 3

3.2 eval 经典陷阱

表达式 结果 原因
eval("123") 123 (int) 数字字符串→整数
eval("'123'") '123' (str) 引号内的引号→字符串
eval("hello") 报错 hello视为变量名，未定义→NameError
eval(89) 报错 eval参数必须是字符串
eval("a+5") 且a未定义 报错 NameError

3.3 eval + input 黄金组合

# 获取数值输入的标准套路
x = eval(input("请输入数字："))    # 用户输入 86 → x = 86 (int)

# 获取表达式结果
x = eval(input("请输入表达式："))  # 用户输入 100+200 → x = 300

# 获取列表
lst = eval(input("输入列表："))    # 用户输入 [1,2,3] → lst = [1,2,3]

3.4 安全警告

eval() 会执行任意代码，不要用在不可信的用户输入上。eval("__import__('os').system('rm -rf /')") 能删系统文件。

说法 对错
eval可以安全处理所有用户输入 ❌
eval只能处理数字 ❌
eval的功能是把字符串转成数字 ❌（不限于数字）

四、代码格式：缩进与注释

4.1 缩进（Indentation）

Python 用缩进表示代码块的层次关系，是语法强制要求，不是美化。

规则 说明
同一层次的语句缩进量必须相同 混用报 IndentationError
Tab 和空格都能缩进 但绝不能混用！
常见缩进量 4个空格
不需要缩进的代码 顶格写，前面不能有空白
unexpected indent 错误 缩进不匹配导致的
分支/循环/函数下 必须有缩进（冒号后面缩进） 
if x > 0:          # 冒号
    print("正数")   # 缩进（属于if）
    x += 1          # 同一层次，缩进量相同
print("结束")       # 顶格（不属于if）

4.2 注释

类型 语法 示例
单行注释 # # 这是注释
多行注释 ''' ... ''' 或 """ ... """ 三个单引号或双引号包裹 
# 单行注释：以井号开头

'''
多行注释
可以跨越多行
'''

"""
这也是多行注释
功能一样
"""

4.3 注释判断题

说法 对错
单行注释以 // 开头 ❌ （Python用 #，// 是整除）
单行注释以 ' 开头 ❌
注释会被解释器执行 ❌
注释可以辅助调试（注释掉代码） ✅
注释内容可包含中文和特殊符号 ✅
注释可以嵌套 ❌
Python有两种注释：单行和多行 ✅
多行注释三引号必须成对出现 ✅

4.4 缩进判断题

说法 对错
缩进仅用于美化代码 ❌（是语法要求）
Tab和空格可以混用 ❌（会导致错误）
可以随意缩进 ❌
缩进是强制的、长度统一的 ✅
缩进不能通过Tab实现 ❌（可以，但不推荐混用）
同一项目中缩进风格应一致 ✅
if分支缩进量须与冒号对齐 ❌（应比if多一层缩进）
缩进错误只影响逻辑，不报语法错误 ❌（会报 IndentationError）

五、IPO 编程方法

5.1 概念

IPO = Input（输入） → Process（处理） → Output（输出）

这是每个程序都遵循的统一运算模式。

5.2 三个环节

环节 含义 例子
I - Input 获取数据 input()、读文件、读数据库
P - Process 处理数据 计算、判断、转换
O - Output 输出结果 print()、写文件、显示

5.3 解决问题六步骤

① 分析问题 → ② 划分边界(IPO描述) → ③ 设计算法 → ④ 编写程序 → ⑤ 调试测试 → ⑥ 升级维护

易错： 第三步是设计算法，不是编写程序！

5.4 IPO 判断题

说法 对错
P 代表 Program ❌（P = Process 处理）
O 代表 Object ❌（O = Output 输出）
Program 是 IPO 组成部分 ❌（I/P/O三个）
输出必须显示在屏幕上 ❌（可写文件、发网络等）
对输入数值求和 → 属于 I ❌（求和是 P，读取才是 I）
输出统计结果 → 属于 P ❌（输出属于 O）

a = 1; b = [1,2,3]; c = "1"

答案与解析

题号 答案 解析
1 B input() 永远返回 str。哪怕用户输入数字123，返回的也是 "123"。
2 B 没用 eval 包裹，input 直接返回字符串 "123"。

4 C sep="-" 把三个数字用-连起来→1-2-3，end="*" 结尾加*不换行→1-2-3*。
5 C print 可以输出任何类型，不限于字符串。自动调用 str() 转换。
6 B eval 把字符串 "3+5" 当 Python 表达式算：3+5=8。
7 C eval("hello") 把 hello 当变量名，未定义→NameError。eval("'hi'") 可以，返回字符串 hi。
8 B sep="_" 把 Hello 和 World 用下划线连接→Hello_World。别跟 end 参数搞混。
9 C Python 用 #。// 是整除运算符，/* 是 C 语言多行注释开头。
10 C 缩进是 Python 的语法强制要求，决定代码块的层次结构。Tab和空格绝不能混用。
11 B I=Input(输入), P=Process(处理), O=Output(输出)。不是 Program。
12 C 步骤：分析问题→划分边界→设计算法→编写程序→调试→维护。千万别记成第三步就写代码。
13 D IPO 三个字母 = Input / Process / Output。Program 不在里面。
14 B print("1",end="") 输出1不换行→print("2") 输出2换行→print("3") 输出3。结果：12 (第一行) + 3 (第二行)。
15 C print(expression) 先算表达式再输出。100+200=300，直接输出 300，没有引号没有等号。
