Python 第四章 浓缩速记卡（数字类型 · 运算符 · 内置函数）

一、数字类型三大类

🧠 费曼：数字三分天下——整数、小数、复数。 整数=你数手指头（1,2,3...），怎么数都没小数点。浮点数=你量身高（1.75米），有小数点。复数=数学课本里的虚数，日常用不到但Python有它。记住口诀：int是整数，float带小数点，complex有个j。

类型 关键字 示例
整数 int 123, 0b101, 0o77, 0xFF
浮点数 float 3.14, 1.23e-4, 0.0
复数 complex 3+4j, complex(1,2)

二、整数的四种进制

进制 前缀 数码范围 示例
十进制 无 0-9 123
二进制 0b / 0B 0,1 0b1010 = 10
八进制 0o / 0O 0-7 0o77 = 63
十六进制 0x / 0X 0-9, a-f/A-F 0xFF = 255

关键规则

0b1010      # ✅ 合法
0B1010      # ✅ 大写B也行
0b12        # ❌ 二进制只有0和1
0o89        # ❌ 八进制没有8和9
0x9g        # ❌ 十六进制没有g
08          # ❌ Python3不允许十进制以0开头

转换函数

bin(100)    # '0b1100100'  十进制→二进制字符串
oct(100)    # '0o144'      十进制→八进制字符串
hex(100)    # '0x64'       十进制→十六进制字符串

十六进制转十进制速算

0x0101 = 1×256 + 0×16 + 1×1 = 257
0o1010 = 1×512 + 0×64 + 1×8 + 0×1 = 520

易错判断题

说法 对错 真相
二进制以0c开头 ❌ 以 0b 开头
八进制以0x开头 ❌ 八进制 0o，十六进制才是 0x
Python有十二进制 ❌ 只有十/二/八/十六进制
某些十进制不能转十六进制 ❌ 所有十进制整数都能转
0bC3F是合法二进制 ❌ 二进制只能0和1

三、浮点数

3.1 科学计数法

1.23e4   = 12300.0       # e = ×10^
1.23e-4  = 0.000123      # e-4 = ×10⁻⁴
2.5e3    = 2500.0
123e+5   = 12300000.0    # ✅ 合法
123e     # ❌ 缺少指数
规则 说明
e 或 E 都可以 大小写不敏感
指数必须是整数 1.2e3.5 ❌
不限定系数格式 123e4 / 1.23e6 / 0.123e7 都合法

3.2 浮点数不确定尾数（头号考点）

🧠 费曼：0.1+0.2≠0.3，就像1/3在十进制里永远写不完。 你用计算器算1÷3=0.33333...，写到纸上永远写不完。计算机用二进制存小数，0.1在二进制里也是个无限循环小数，存不下就截断，截断就有误差。所以0.1+0.2=0.30000000000000004。这跟Python没关系，是所有语言用IEEE 754的结果。

0.1 + 0.2              # 0.30000000000000004 （不是0.3！）
0.1 + 0.2 == 0.3       # False！

原因： 某些十进制小数无法精确转换为二进制（如0.1在二进制中是无限循环小数），IEEE 754存储产生误差。

应对： - round(0.1+0.2, 2) → 0.3 - 使用 decimal 模块 - 不直接 == 比较浮点数

值的大小比较
1.23e4 = 12300 12.3e3 = 12300
0.123e5 = 12300 123e3 = 123000 ← 最大

四、复数

3 + 4j          # 复数，虚部用 j 或 J（不是 i！）
complex(10.99)  # (10.99+0j)
complex(45, 6)  # (45+6j)

# 属性
z = 3 + 4j
z.real          # 3.0 (float类型)
z.imag          # 4.0 (float类型)
说法 对错
虚部用 i 表示 ❌ Python用 j 或 J
虚部用 C/c 表示 ❌
实部和虚部都是整数类型 ❌ 都是 float 类型
3+4j 合法 ✅

五、算术运算符

5.1 七大运算符

运算符 含义 示例 结果
+ 加 3 + 2 5
- 减 3 - 2 1
* 乘 3 * 2 6
/ 真除（返回float） 5 / 2 2.5
// 整除（向下取整） 5 // 2 2
% 取余（模） 5 % 2 1
** 幂 2 ** 3 8

5.2 优先级（从高到低）

** → * / // % → + -

3 + 2 * 3 ** 2    # **先算: 3**2=9 → 2*9=18 → 3+18=21
2 ** 3 * 4 % 5    # = 8*4%5 = 32%5 = 2

5.3 两个高频应用

# 判断偶数
x % 2 == 0        # ✅ 正确
x // 2 == 0       # ❌ 错误（整除判偶不对）

# 取千位数字（四位数）
a // 1000         # ✅ 千位

# 取前两位+后两位（如9517 → 95+17）
a // 100 + a % 100                 # ✅ 95 + 17 = 112
b, c = divmod(a, 100); b + c       # ✅
int(a / 100) + a % 100             # ✅（a/100=95.17 → int→95）
a / 100 + a % 100                  # ❌（95.17 + 17 = 112.17）

5.4 常见应用题

# 200张百元钞票均分给3人
200 // 3      # 66 每人几张
200 % 3       # 2  还剩几张

# 70万小时 = 多少周岁
70 * 10000 // 24 // 365

# 平均寿命78.9岁 = 多少小时
78.9 * 365 * 24

5.5 右结合性（**是特例）

2 ** 3 ** 0    # 右结合：先算 3**0=1，再算 2**1=2
               # NOT (2**3)**0=1！

5.6 运算符判断题

说法 对错
// 是整除，/ 是浮点除 ✅
** 的 y 必须是整数 ❌ （4**0.5=2.0 合法）
a**b 只能用 ** 算 ❌ 也可用 pow(a,b)
整除只能用 a//b 和 a%b ❌ 也可用 divmod(a,b)
& 是算术运算符 ❌ 是位运算符
9 / 3 结果是 int ❌ Python3 中 / 总是返回 float（3.0）
整数与浮点数运算结果是整数 ❌ 结果是 float

答案与解析

题号 答案 解析
1 B IEEE 754 浮点误差→0.1+0.2=0.30000000000000004，不等于0.3。判断浮点数相等是经典坑。
2 B 0b1010=10。A含非法数字2，C是十六进制，D是八进制。
3 C int() 向零截断，不四舍五入。3.9→3，-3.9→-3。
4 B Python3 中 / 永远返回 float，即使整除也是 3.0。// 才返回 int。
5 C Python 整数四大进制：十(无前缀)、二(0b)、八(0o)、十六(0x)。没有十二进制。
6 B 0x0101 = 1×16² + 0×16¹ + 1×16⁰ = 256+0+1 = 257。
7 B 优先级：** > * > +。3²=9, 2×9=18, 3+18=21。
8 B 偶数÷2余0→x%2==0。A是错的（x//2==0 只在 x=0或1时成立）。
9 C A的Unicode码=65。a=97，z=122。务必记住A=65、a=97。
10 C pow(3,3,2) = 3³%2 = 27%2 = 1。第三个参数是取模。
11 B Python 用 j 或 J。数学课本用 i，Python 用 j。别搞混。
12 A round(3.14159, 2) = 3.14（保留两位小数，四舍五入）。
13 A divmod(被除数, 除数) 返回元组 (商, 余数)。20÷3=6余2→(6,2)。
14 B bin() 返回带 0b 前缀的字符串。不带前缀的是数字本身。
15 C a*=2+3**2 → 先算右边：3²=9，2+9=11，然后 a=10×11=110。增强赋值的右操作数先整算。
