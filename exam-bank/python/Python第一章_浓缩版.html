Python 第一章 浓缩速记卡

一、计算机语言发展史（三层）

🧠 费曼：机器语言=哑语手势，汇编语言=单词缩写，高级语言=完整句子。 你想让一个外国人帮你做事。机器语言=你用手比划（二进制），他秒懂但你不能说人话。汇编语言=你用单词缩写比如"WTR=倒水"，比手划快但还是很累。高级语言=你直接说"请帮我倒杯水"，说完他找个翻译官（编译器/解释器）翻给他听。Python就是那个你说人话的语言。

机器语言 → 汇编语言 → 高级语言
(二进制)   (助记符)   (接近自然语言)
语言 特点 执行方式
机器语言 二进制代码，唯一能直接被CPU执行，依赖硬件，速度最快 无需翻译
汇编语言 用助记符替代二进制，需汇编器转换，依赖硬件 汇编
高级语言 可读性强、可移植好、抽象度高，接近自然语言 编译或解释

易错点： - 自然语言（中文/英文）不属于程序设计语言 - 机器语言可读性最差、编写效率最低 - 高级语言运行速度 不是 最快的

二、编译型 vs 解释型

🧠 费曼：编译=整本书翻译完再给人看，解释=找个翻译在旁边一句一句翻。 你要给一个外国人看一本中文小说。编译型：先把整本书翻译成英文印出来（生成.exe），他直接读英文，速度飞快。解释型：你一句一句念中文，翻译在旁边一句一句翻给他听（Python解释器），随时能打断问问题（调试方便），但整体看完整本书的速度慢。

编译型 (C/C++) 解释型 (Python/JS)
翻译方式 一次性全部翻译为机器码 逐行解释执行
生成目标文件 有 (.exe等) 无
执行速度 快 慢
可移植性 弱 强
调试 编译时发现错误 运行时暴露错误
代码保护 好(只分发机器码) 差(源码暴露)

关键判断题： - Python是解释型语言（不是编译型）✅ - 编译型语言执行速度快 ✅ - 解释型语言可移植性强 ✅ - 解释型语言交互性好 ✅ - "Python代码需先编译成机器码再执行" ❌

填空题标配答案： 高级语言执行方式 = 编译执行 + 解释执行

四、Python 核心特点

✅ 是：

  • 开源免费（GNU协议）
  • 完全面向对象（一切皆为对象）
  • 跨平台（解释器统一运行环境）
  • 语法简洁、强制缩进
  • 粘性扩展（可集成C/C++代码）
  • 类库丰富（pip安装第三方库）
  • 支持中文
  • 解释型脚本语言

❌ 不是：

  • 运行速度极快（Python慢，C/C++快）
  • 编译型语言
  • 执行高效
  • 需要先声明变量类型（动态类型，直接赋值）

Python之禅

import this  # 查看完整准则

核心理念：优美优于丑陋、明确优于隐晦、简单优于复杂、可读性很重要

五、开发环境

知识点 答案
Python自带IDE IDLE
交互式环境提示符 >>>
源文件扩展名 .py
运行快捷键 F5
新建文件快捷键 Ctrl+N
打开文件快捷键 Ctrl+O
安装第三方库命令 pip install xxx
退出IDLE命令 exit()
安装关键操作 勾选 "Add Python to PATH"

IDLE两种模式：

  • 交互式（Shell）：即时执行单行，适合调试验证，代码不会自动保存
  • 文件式（Editor）：编写完整.py文件 → 保存 → F5运行，适合大型程序

其他工具：

  • Anaconda：自带大量库，适合大型项目，跨平台开源
  • PyCharm / VS Code：第三方IDE（非Python自带）

易错点：

  • 不同操作系统（Windows/Mac）需要不同安装包
  • IDLE 自带于Python安装包中
  • IDLE 不自带大量第三方库

答案与解析

题号 答案 解析
1 B 机器语言由二进制代码组成，是CPU唯一能直接执行的。A需要汇编器，C/D需要编译/解释器翻译。
2 B 机器语言(1940s)→汇编语言(1950s)→高级语言(1960s+)，抽象程度逐步提高。
3 C 汇编→机器码叫"汇编"，高级语言→机器码才叫"编译"。这是常考题，别搞混。
4 C 高级语言运行速度次于机器语言，机器语言直接执行最快。"运行速度最快"不是高级语言特点。
5 C Python属于高级语言，也是解释型脚本语言。
6 C 解释型语言逐行翻译，执行效率比编译型低。A/B/D都是解释型优点。
7 A Guido van Rossum于1991年首次公开发布Python。2008年是Python 3.0发布年份，别搞混。
8 C Python 3.0 = 2008年。Python 3.x 不兼容 Python 2.x，这是重要考点。
9 C Python名字来自BBC喜剧《Monty Python's Flying Circus》，跟蟒蛇无关。选A必错。
10 C Python缺点就是运行速度相对慢、并行计算弱、源码难加密。"执行高效"是C/C++的特点。
11 B import this 输出《Python之禅》(The Zen of Python)。核心：优美>丑陋，简单>复杂。
12 D IDLE是Python安装包自带的轻量级IDE。PyCharm/VS Code是第三方工具。
13 B F5 = 运行。Ctrl+N = 新建，Ctrl+O = 打开，Ctrl+S = 保存。四个快捷键都常考。
14 C Python源文件必须以 .py 结尾。这是基本常识。
15 C 不勾PATH=cmd里输python没反应=第一节课最常见翻车现场。必须勾选。
