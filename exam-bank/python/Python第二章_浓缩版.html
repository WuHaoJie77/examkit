Python 第二章 浓缩速记卡（变量 · 字符串 · 赋值）

一、变量与标识符

🧠 费曼：变量名 = 储物柜标签。 你去健身房，前台给你一个柜子，贴个标签写上你的名字。标签可以换（重新赋值），柜子里放的东西也可以换（类型可变）。但你不能先把东西放进去再贴标签——必须先声明/赋值再用。Python比C语言懒：你不用提前说"我要一个放鞋的柜子"，直接扔东西进去，它自动识别类型。

1.1 变量核心规则

规则 说明
不需要声明类型 直接赋值即创建，x = 5 自动确定 x 为 int
动态类型 同一变量可先后赋不同类型值：x=5; x="hello" ✅
先赋值再使用 未赋值的变量直接使用 → NameError
值可变，类型可变 变量值在运行中可随意改

1.2 标识符命名规则（三必须 + 三不能）

✅ 必须： - 首字符必须是 字母 / 下划线 / 汉字 - 后续字符可以是 字母 / 数字 / 下划线 / 汉字 - 区分大小写（Name ≠ name ≠ NAME）

❌ 不能： - 不能以数字开头（123abc ❌） - 不能含空格（my var ❌） - 不能含特殊符号（$var / my-var / a!1 ❌） - 不能是关键字（if / for / class ❌）

1.3 合法 vs 非法 速查

合法 ✅ 非法 ❌ 原因
_myVar 123var 数字开头
MyGod5 5MyGod 数字开头
a_1 a 1 / a!1 / 1a 空格/符号/数字开头
TempStr if 关键字
_name $var_1 $ 非法字符
If Draw Python 空格
Templist 33_keyword 数字开头
I my-variable 连字符 - 不合法
α = 3.14 — Python3 支持 Unicode 标识符 ✅

概念： Python 预定义的、有特殊含义的单词，不能当变量名。 大小写敏感： if 是关键字，但 If / IF 不是 → 可以当变量名。

False True None and or not
if elif else for while break continue

try except finally raise pass del

二、字符串与切片（重点！题量最大）

🧠 费曼：切片 = 切面包。 你有一条长面包（字符串），想切出中间一段。你告诉师傅：从第3片开始切，切到第7片为止（但第7片不给你，只给到第6片！）。s[3:7] 就是这个意思——start包含，end不包含。如果你从右往左切（步长为负），那就是倒着切。s[::-1] = 把面包整个翻过来。

2.1 字符串基础

  • 用 " " 或 ' ' 括起来
  • s="123" 是字符串，s=123 是整数
  • "sm" 是字符串常量，sm 是变量名 —— 引号决定一切

2.2 索引（取单个字符）

正向索引： 0    1    2    3    4
          P    y    t    h    o    n
反向索引：-6   -5   -4   -3   -2   -1
表达式 结果 说明
"Python"[0] P 第一个
"Python"[4] o 正向第5个
"Python"[-1] n 最后一个
"Python"[-2] o 倒数第二个

中文字符串同理： - "中华人民共和国"[3] = 民 - "中华人民共和国"[-4] = 民 - 正向和反向都能取到同一字符

2.3 切片（取子串）—— 最核心

语法：s[start : end : step]
              ↑      ↑     ↑
           包含   不包含  步长(可省略，默认1)

铁律：end 索引对应的字符不包含在结果中！

表达式 结果 规律
s[:] 完整字符串 全取
s[m:] 从 m 到末尾 左边界包含
s[:n] 从开头到 n-1 右边界不包含
s[m:n] 从 m 到 n-1 取 n-m 个字符
s[-n:] 最后 n 个字符 常用技巧
s[:-n] 去掉最后 n 个 常用技巧
s[::k] 每隔 k-1 个取一个 跳步切片

2.4 切片高频考题

题目 答案 关键
"abcdef"[0:-1] abcde -1 是 f 不包含
"Python"[ :3] Pyt 0,1,2 → 不包含索引3
"abcde"[2:4] cd 不是 cde！索引4(e)不包含
"abcde"[2:] cde 从c到末尾
"Hello World"[6:] World 空格算一个位置
"Python Programming"[-5:] mming 最后5个字符

2.5 中文字符串切片

s = "河南财经政法大学"
索引:    0  1  2  3  4  5  6
字符:    河 南 财 经 政 法 大 学
反向:   -8 -7 -6 -5 -4 -3 -2 -1
表达式 结果
s[0] / s[-8] 河
s[2:] 财经政法大学
s[-2:] 大学
s[:2] 河南
s[2:6] 财经政法
s[6:7] → 只取 大 ❌ 想取"大学"用 s[-2:]

2.6 切片填空题速算口诀

拿到字符串先数长度，正向标序号，反向从-1倒数。 end不包含是丢分第一原因。

三、赋值语句

3.1 基本赋值

x = 5           # 基本赋值
x += 3          # 增量赋值，等价 x = x + 3
x *= 2          # 等价 x = x * 2
a %= b          # 等价 a = a % b

3.2 同步赋值（多变量同时赋值）

x, y = 10, 20           # x=10, y=20
a, b, c = 1, 2, 3       # a=1, b=2, c=3
x, y = y, x             # 交换！x=20, y=10
a, b = b, a+b           # 右侧先全部算完再赋值

关键规则： - 等号右侧所有表达式先全部计算，再一次性赋给左侧 - a, b = b, a+b ≠ a=b; b=a+b —— 同步赋值用原始值算，逐行赋值用更新值算

# 同步赋值
x, y = 3, 5
x, y = y, x + y    # x=5, y=3+5=8

# 逐行赋值（不等价！）
x = y               # x=5
y = x + y           # y=5+5=10 → 结果不同！

3.3 链式赋值

a = b = c = 10    # 三个变量都是10 ✅

3.4 赋值铁律

规则 示例
左侧必须是变量 10 = a ❌ x+1 = x ❌
右侧可以是表达式 x = y + 1 ✅
字符串字面量不能放左侧 "abc" = x ❌

3.5 续行与分隔

  • \ 续行符：一行写不下时用
  • ; 分隔同行的多条语句（用英文分号，不能用中文）
  • 注释行不能用 \ 续行

四、特殊约定（判断题陷阱）

全大写变量不可修改 ❌ 只是约定，Python不强制，改了不报错
