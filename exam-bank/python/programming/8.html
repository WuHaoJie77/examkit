8-1(5.0分)简单if-else
输入一个整数，判断奇偶。
▼ 预期运行结果
请输入一个整数：7
7是奇数
请输入一个整数：8
8是偶数
✅ 参考代码
n=int(input("请输入一个整数："))
if n%2==0:
    print(f"{n}是偶数")
else:
    print(f"{n}是奇数")

🔑 关键：if-else二选一，条件True走if，否则走else。

8-2(5.0分)多分支if-elif-else
输入分数(0-100)，输出等级：≥90→优秀，≥80→良好，≥70→中等，≥60→及格，<60→不及格。
▼ 预期运行结果
请输入分数：85
等级：良好
请输入分数：55
等级：不及格
✅ 参考代码
s=float(input("请输入分数："))
if s>=90: g="优秀"
elif s>=80: g="良好"
elif s>=70: g="中等"
elif s>=60: g="及格"
else: g="不及格"
print(f"等级：{g}")

🔑 关键：elif从上到下匹配，只执行第一个满足的。≥90必须放最前面。

8-3(5.0分)嵌套分支
输入性别和身高安排座位：男→1号厅，女→2号厅。男≥180/女≥170→5-8排，否则→1-4排。必须用嵌套if。
▼ 预期运行结果
请输入性别(男/女)：男
请输入身高(cm)：182
请到1号厅5-8排
请输入性别(男/女)：女
请输入身高(cm)：165
请到2号厅1-4排
✅ 参考代码
g=input("请输入性别(男/女)：")
h=int(input("请输入身高(cm)："))
if g=="男":
    if h>=180: print("请到1号厅5-8排")
    else: print("请到1号厅1-4排")
else:
    if h>=170: print("请到2号厅5-8排")
    else: print("请到2号厅1-4排")

🔑 关键：外层if-else分流，内层if-else分排。

8-4(5.0分)三元条件表达式
输入两个数，用一行三元表达式输出较大者：X if 条件 else Y。
▼ 预期运行结果
请输入第一个数：15
请输入第二个数：23
较大的数是：23
✅ 参考代码
a=float(input("请输入第一个数："))
b=float(input("请输入第二个数："))
print(f"较大的数是：{a if a>b else b}")

🔑 关键：三元表达式是if-else的简写。适合简单二选一。

8-5(5.0分)独立if vs if-elif
用两个独立if判断：数是否>10，是否>20。观察和elif的区别。
▼ 预期运行结果
请输入一个数：25
大于10: True 大于20: True
请输入一个数：15
大于10: True 大于20: False
✅ 参考代码
n=float(input("请输入一个数："))
if n>10: print("大于10: True")
else: print("大于10: False")
if n>20: print("大于20: True")
else: print("大于20: False")

🔑 关键：独立if每个都判断；elif只执行第一个满足的。两个条件都需判断时用独立if。
