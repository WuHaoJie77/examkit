12-1(5.0分)append添加
空列表循环输入5个数，每次append到末尾。
▼ 预期运行结果
请输入第1个数：10
...
请输入第5个数：50
最终列表：[10, 20, 30, 40, 50]
✅ 参考代码
lst=[]
for i in range(1,6):
    lst.append(int(input(f"请输入第{i}个数：")))
print(f"最终列表：{lst}")

🔑 关键：append(x)末尾添加一个。extend()拆开添加多个。

12-2(5.0分)insert插入
定义lst=[1,2,4,5]，在索引2处插入3→[1,2,3,4,5]。
▼ 预期运行结果
插入前：[1, 2, 4, 5] 插入后：[1, 2, 3, 4, 5]
✅ 参考代码
lst=[1,2,4,5]
print("插入前：",lst)
lst.insert(2,3)
print("插入后：",lst)

🔑 关键：insert(index,value)指定位置插入。insert(-1,x)插在倒数第二。

12-3(5.0分)pop/remove删除
定义lst=['a','b','c','d','e']，pop删除最后，remove删除'b'。
▼ 预期运行结果
pop后: ['a', 'b', 'c', 'd']，弹出: e remove后: ['a', 'c', 'd']
✅ 参考代码
lst=["a","b","c","d","e"]
p=lst.pop()
print(f"pop后: {lst}，弹出: {p}")
lst.remove("b")
print(f"remove后: {lst}")

🔑 关键：pop()按索引删除返回被删值。remove(x)按值删第一个。找不到报错。

12-4(5.0分)排序与反转
列表[8,3,1,6,4]，升序→降序→反转。
▼ 预期运行结果
升序: [1, 3, 4, 6, 8] 降序: [8, 6, 4, 3, 1] 反转: [1, 3, 4, 6, 8]
✅ 参考代码
lst=[8,3,1,6,4]
lst.sort()
print("升序:",lst)
lst.sort(reverse=True)
print("降序:",lst)
lst.reverse()
print("反转:",lst)

🔑 关键：sort(reverse=True)降序。reverse()只翻转不排序。都原地修改。

12-5(5.0分)综合：待办事项
维护待办列表：输入add添加、done删除、show显示、quit退出。
▼ 预期运行结果
add 写作业
add 复习
show
done 写作业
show
quit
['写作业'] ['写作业', '复习'] ['复习']
✅ 参考代码
todos=[]
while True:
    cmd=input("> ")
    if cmd=="quit": break
    elif cmd=="show": print(todos)
    elif cmd.startswith("add "): todos.append(cmd[4:])
    elif cmd.startswith("done "):
        item=cmd[5:]
        if item in todos: todos.remove(item)
        else: print(f"不存在: {item}")

🔑 关键：综合运用append/remove/in/遍历。
