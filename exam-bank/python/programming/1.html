1-1(5.0分)print输出多行文本
编写程序，使用一个print语句输出以下三行文字：
第一行：欢迎来到Python世界！
第二行：让我们一起学习编程。
第三行：加油！
要求不能使用三个print。
▼ 预期运行结果
欢迎来到Python世界！ 让我们一起学习编程。 加油！
✅ 参考代码
print("欢迎来到Python世界！\n让我们一起学习编程。\n加油！")

🔑 关键：用 \n 在字符串内换行，一个 print 搞定多行输出。

1-2(5.0分)input交互式计算
编写程序，让用户输入两个整数，计算并输出它们的和与积。
输出格式：和=X, 积=Y
▼ 预期运行结果
请输入第一个整数：3
请输入第二个整数：5
和=8, 积=15
✅ 参考代码
a = int(input("请输入第一个整数："))
b = int(input("请输入第二个整数："))
print(f"和={a+b}, 积={a*b}")

🔑 关键：input() 返回字符串，用 int() 转成整数才能计算。

1-3(5.0分)type查看变量类型
编写程序，分别创建整数、浮点数、字符串三个变量，用 type() 打印每个变量的类型。
▼ 预期运行结果
✅ 参考代码
a = 42
b = 3.14
c = "Hello"
print(type(a))
print(type(b))
print(type(c))

🔑 关键：type() 是查看变量类型的内置函数，不改变变量的值。

1-4(5.0分)print的sep和end参数
编写程序，用一行print语句输出三个数字 1、2、3，要求它们之间用 -> 分隔，末尾输出一个感叹号。
▼ 预期运行结果
1 -> 2 -> 3!
✅ 参考代码
print(1, 2, 3, sep=" -> ", end="!")

🔑 关键：sep 控制分隔符（默认空格），end 控制结尾字符（默认换行）。

1-5(5.0分)注释与代码可读性
编写程序，包含单行注释和多行注释，用 print 输出一句话说明注释的作用。
▼ 预期运行结果
注释可以提高代码的可读性！
✅ 参考代码
# 这是单行注释
"""
这是多行注释
可以写多行文字
"""
print("注释可以提高代码的可读性！")

🔑 关键：# 用于单行注释，三引号 '''...''' 或 """...""" 用于多行注释。
