7-1(5.0分)比较运算符
定义a=10,b=20，输出a>b、a==b、a!=b结果。
▼ 预期运行结果
a > b: False a == b: False a != b: True
✅ 参考代码
a,b=10,20
print(f"a > b: {a>b}\na == b: {a==b}\na != b: {a!=b}")

🔑 关键：比较运算符返回True/False。==判断相等，!=判断不等。

7-2(5.0分)and逻辑与
输入一个数，判断是否在[10,20]区间内（含边界），用and。
▼ 预期运行结果
请输入一个数：15
15在区间[10,20]内吗？ True
请输入一个数：25
25在区间[10,20]内吗？ False
✅ 参考代码
n=float(input("请输入一个数："))
r=n>=10 and n<=20
print(f"{n}在区间[10,20]内吗？ {r}")

🔑 关键：and两边都为True才True。Python支持10<=n<=20链式比较。

7-3(5.0分)or逻辑或
输入一个字母，判断是否元音（a/e/i/o/u），用or。
▼ 预期运行结果
请输入一个字母：a
a是元音字母吗？ True
请输入一个字母：b
b是元音字母吗？ False
✅ 参考代码
ch=input("请输入一个字母：").lower()
r=ch=="a" or ch=="e" or ch=="i" or ch=="o" or ch=="u"
print(f"{ch}是元音字母吗？ {r}")

🔑 关键：or任一边True就True。.lower()统一转小写简化判断。

7-4(5.0分)not逻辑取反
输入一个数，判断不是偶数（即奇数），用not。
▼ 预期运行结果
请输入一个整数：7
7不是偶数吗？ True
请输入一个整数：8
8不是偶数吗？ False
✅ 参考代码
n=int(input("请输入一个整数："))
r=not(n%2==0)
print(f"{n}不是偶数吗？ {r}")

🔑 关键：not取反。n%2==0判断偶数→not后变判断奇数。

7-5(5.0分)组合条件：闰年判断
输入年份，判断闰年。规则：能被4整除但不能被100整除，或能被400整除。
▼ 预期运行结果
请输入年份：2000
2000是闰年吗？ True
请输入年份：1900
1900是闰年吗？ False
✅ 参考代码
y=int(input("请输入年份："))
leap=(y%4==0 and y%100!=0) or (y%400==0)
print(f"{y}是闰年吗？ {leap}")

🔑 关键：括号控制优先级。优先级：not>and>or，不确定时加括号。
