11-1(5.0分)列表索引与切片
定义lst=[10,20,30,40,50]，输出第一个、最后一个、前三。
▼ 预期运行结果
第一个: 10 最后一个: 50 前三个: [10, 20, 30]
✅ 参考代码
lst=[10,20,30,40,50]
print("第一个:",lst[0])
print("最后一个:",lst[-1])
print("前三个:",lst[:3])

🔑 关键：列表索引/切片与字符串同。lst[0]返回元素，lst[:3]返回列表。

11-2(5.0分)列表遍历统计
输入列表，统计偶数个数。
▼ 预期运行结果
请输入一个列表：[1,2,3,4,5,6]
偶数个数：3
✅ 参考代码
lst=eval(input("请输入一个列表："))
c=sum(1 for x in lst if x%2==0)
print(f"偶数个数：{c}")

🔑 关键：sum(1 for x in lst if cond)优雅计数法。

11-3(5.0分)列表推导式
用列表推导式生成1到20中所有奇数的平方。
▼ 预期运行结果
[1, 9, 25, 49, 81, 121, 169, 225, 289, 361]
✅ 参考代码
res=[x**2 for x in range(1,21) if x%2==1]
print(res)

🔑 关键：[表达式 for 变量 in 可迭代 if 条件]一行替代for+if+append。

11-4(5.0分)sort vs sorted
对比sort()原地排序和sorted()创建新列表的区别。
▼ 预期运行结果
sort()后原列表: [1, 2, 5, 8, 9] sorted()返回新列表: [1, 2, 5, 8, 9] 原列表未变: [5, 2, 8, 1, 9]
✅ 参考代码
lst=[5,2,8,1,9]
lst.sort()
print("sort()后原列表:",lst)
lst2=[5,2,8,1,9]
print("sorted()返回新列表:",sorted(lst2))
print("原列表未变:",lst2)

🔑 关键：sort()原地修改返回None。sorted()返回新列表不修改原列表。

11-5(5.0分)in/not in判断
输入一个数，判断是否在列表中存在，存在则输出索引。
▼ 预期运行结果
请输入要查找的数：9
9在列表中，索引为3
请输入要查找的数：10
10不在列表中
✅ 参考代码
lst=[3,7,2,9,5]
n=int(input("请输入要查找的数："))
if n in lst:
    print(f"{n}在列表中，索引为{lst.index(n)}")
else:
    print(f"{n}不在列表中")

🔑 关键：先in检查再index()获取索引，避免ValueError。
