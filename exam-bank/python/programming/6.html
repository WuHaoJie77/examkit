6-1(5.0分)find查找子串
定义s="hello world hello"，用find()找第一个和最后一个"hello"位置。
▼ 预期运行结果
第一个hello位置: 0 最后一个hello位置: 12
✅ 参考代码
s="hello world hello"
print("第一个hello位置:",s.find("hello"))
print("最后一个hello位置:",s.rfind("hello"))

🔑 关键：find()左找，rfind()右找。找不到返回-1（不报错）。index()找不到报错。

6-2(5.0分)replace替换文本
定义s="I like cat, cat is cute"，把所有cat替换为dog。
▼ 预期运行结果
I like dog, dog is cute
✅ 参考代码
s="I like cat, cat is cute"
print(s.replace("cat","dog"))

🔑 关键：replace(old,new)替换所有匹配。replace(old,new,count)限制次数。

6-3(5.0分)split分割字符串
定义s="apple,banana,orange"，按逗号分割成列表，遍历输出。
▼ 预期运行结果
apple banana orange
✅ 参考代码
s="apple,banana,orange"
for f in s.split(","):
    print(f)

🔑 关键：split(sep)按分隔符切分返回列表。不指定时默认按空白分割。

6-4(5.0分)strip去除空白
定义s=" Hello World "，输出去两端、去左、去右空白的结果。
▼ 预期运行结果
去两端: 'Hello World' 去左: 'Hello World ' 去右: ' Hello World'
✅ 参考代码
s="   Hello World   "
print("去两端:",repr(s.strip()))
print("去左:",repr(s.lstrip()))
print("去右:",repr(s.rstrip()))

🔑 关键：strip()去两端，lstrip()去左，rstrip()去右。repr()显示引号看清空白。

6-5(5.0分)join连接列表
定义words=['Python','is','fun']，用空格连接成句子。
▼ 预期运行结果
Python is fun
✅ 参考代码
words=["Python","is","fun"]
print(" ".join(words))

🔑 关键："分隔符".join(列表)拼接成字符串。split的反操作。
