成本会计 第四章 完工产品与在产品分配 浓缩速记卡

⚠️ 挂科重灾区！全书的计算核心 | 31题 | 预计用时60分钟

💡 费曼类比：完工和在产品分配就像给一群人和半碗饭分账单——完工产品是吃饱走人的，在产品是还在吃的。你不能把整桌菜钱全算到走的人头上，也不能平均分——得看每个人吃了多少（约当产量）。

一、七种分配方法对比表（必背！）

方法 适用条件 核心逻辑 关键坑
不计算在产品成本 月末在产品数量很小 本月生产费用=完工产品成本 数量很小才行，不是"变化小"
按年初固定数计算 在产品数量较大但变化不大 每月在产品成本固定=年初数，本月费用=完工成本 年末需调整回实际数
按所耗原材料计价 材料费占比很大 在产品只计材料费，加工费全给完工 仅适用于材料密集型（如面粉厂）
约当产量比例法 数量大+变化大+料工费比重相差不多 把在产品按完工程度折算为完工品 投料程度≠加工程度！分别算
在产品按定额成本计价 定额健全+在产品数量变化不大 在产品=定额成本，差异全给完工 变化大→完工成本可能为负数！
定额比例法 定额健全+在产品数量变化较大 按定额比例分配实际费用，差异共担 与定额成本法相反：差异由双方共担
完工产品法 在产品已接近完工 在产品视同完工产品，按实际产量分配 仅适用于已基本完工的情况

选择方法的口诀："量小不算，量大不变用固定，料重用材料，料工费平衡约当，定额稳用定额法（变大小决定比例还是成本），接近完工直接分。"

二、约当产量法完整流水线（★★★ 全书最重要）

总流程图

Step 1: 判断投料方式 → 算材料约当产量
Step 2: 算加工程度 → 算加工费约当产量
Step 3: 分别计算材料分配率和加工费分配率
Step 4: 分配 → 完工产品成本 = 完工产量×分配率

子流程A：投料程度计算（三种情形）

投料方式 投料程度计算 约当产量
①一次投料（生产开始全部投入） 投料程度 = 100% 材料约当产量 = 在产品实际数量
②分工序一次投料（每道工序开始时投） 某工序投料程度 = 前面工序累计定额/总定额 约当产量 = Σ(各工序在产品×该工序投料程度)
③陆续投料（与加工进度一致） 投料程度 = 加工程度 材料约当产量 = 加工费约当产量
③'陆续投料（与加工进度不一致） 单独计算投料程度 与加工程度分开算

例题（第③'种）：两道工序，定额20kg+30kg=50kg。陆续投入，投料与加工进度不一致。 第一道投料程度 = (20×50%)/50 = 20% 第二道投料程度 = (20+30×50%)/50 = 70% 每道工序内按50%算，前面工序全额

子流程B：加工程度计算

公式：

某工序加工程度 = (前面各工序工时定额之和 + 本工序工时定额×50%) / 总工时定额

注意：前面工序是全额定額（已完成），本工序是50%（进行中）。

例题：三道工序40h, 16h, 24h，总80h。 - 第一道加工程度 = (40×50%)/80 = 25% - 第二道加工程度 = (40 + 16×50%)/80 = 60% - 第三道加工程度 = (40+16 + 24×50%)/80 = 85%

判断："某道工序加工程度=(本工序工时定额+前面各工序×50%)/总定额" → ❌ 错！是前面全額+本工序×50%。

子流程C：加工程度快速算法（各工序统一50%）

如果不分别测定各工序，对各工序在产品统一按50%计算加工程度。简单但粗糙。

三、两种定额法对比（高频混淆）

在产品按定额成本计价法 定额比例法
在产品数量变化 变化不大 变化较大
差异归属 差异全部由完工产品负担 差异由完工和在产品共同负担
计算顺序 先算在产品定额成本→倒挤完工成本 先算分配率→双方按定额比例分
变化大时的后果 完工成本可能为负数！ 正常分配

判断："定额成本法下差异全部计入在产品成本" → ❌ 错！差异计入完工产品成本。 判断："定额比例法下差异由完工和在产品共同负担" → ✅ 对。

四、广义在产品

包括 不包括
✅ 正在加工中的在产品 ❌ 已验收入库的产成品
✅ 已完成部分步骤仍需继续加工的半成品 ❌ 已销售的产成品
✅ 等待返修的废品
✅ 尚未验收入库的产成品

判断："等待返修的废品属于广义在产品" → ✅ 对！

五、例题精练

例题1：约当产量法——一次投料+加工程度

某产品本月完工600件，月末在产品200件。原材料一次投入。在产品加工程度50%。月初在产品+本月发生：直接材料80,000元，直接人工22,000元，制造费用11,000元。

解：

Step 1：材料约当产量（一次投料→投料程度100%） 材料约当产量 = 200 × 100% = 200件 材料总约当产量 = 600 + 200 = 800件

Step 2：加工费约当产量（加工程度50%） 加工约当产量 = 200 × 50% = 100件 加工总约当产量 = 600 + 100 = 700件

Step 3：分配率 直接材料分配率 = 80,000 ÷ 800 = 100元/件 直接人工分配率 = 22,000 ÷ 700 = 31.43元/件 制造费用分配率 = 11,000 ÷ 700 = 15.71元/件

Step 4：分配 完工产品成本 = 600×(100+31.43+15.71) = 88,286元 在产品成本 = 80,000+22,000+11,000 - 88,286 = 24,714元 验证：材料200×100=20,000 + 加工100×(31.43+15.71)=4,714 → 24,714 ✓

坑点：材料一次投料→材料约当产量=在产品实际数量（200），加工约当产量=200×50%=100。两个约当产量不同！

例题2：约当产量法——分工序测加工程度

三道工序：40h/16h/24h，总80h。完工1,000件，在产品：第一道100件，第二道200件，第三道150件。本月加工费用56,700元。

解：

各工序加工程度（前面已验证）： 第一道=(40×50%)/80=25%，第二道=(40+16×50%)/80=60%，第三道=(40+16+24×50%)/80=85%

加工费约当产量： = 100×25% + 200×60% + 150×85% = 25 + 120 + 127.5 = 272.5件

分配率 = 56,700 ÷ (1,000 + 272.5) = 44.56元/件

完工加工费 = 1,000 × 44.56 = 44,560元 在产品加工费 = 272.5 × 44.56 = 12,140元

例题3：盘亏处理

在产品因意外灾害盘亏，扣除残值和保险赔偿后的净损失→借记营业外支出。

在产品盘盈，经审批后→贷记管理费用（冲减）。

题4：用题3数据，改用定额比例法分配。

题5：判断对错并改正："某道工序在产品加工程度=(本工序工时定额+前面各工序工时定额×50%)/产品工时定额。"

七、答案与解析

选择题答案

题号 答案 思路 推导 坑点
1 B 七法选择第一步 在产品量很小→忽略不计→不计算在产品成本法 不是"变化小"，是"数量小"——两回事
2 B 量大但变化不大 变化不大→可以"固定"→年初固定数法 不能用不计算法（量不小），不能用约当（变化不大不需要那么精确）
3 B 约当产量法适用三条件 量大+变化大+料工费均衡=约当产量法的标准场景 这是约当产量法最经典的适用描述，记住这三个条件
4 B 加工程度公式 (40+16×50%)/80=48/80=60% 本工序50%+前面全額，不是本工序全額+前面50%
5 B 一次投料→投料100% 投料程度100%→在产品视同完工→材料按实际产量比例分 选项C是加工费的分配比例，此处问的是材料→用实际产量
6 C 定额成本法的缺陷 数量变化大→定额与实际差异大→差异全由完工承担→可能负 这是定额成本法的致命缺陷，适合考单选
7 C 定额比例法的差异归属 定额比例法=按定额比例分实际费用→差异共担 与定额成本法相反记忆：一个独担、一个共担
8 C 广义在产品的边界 已入库产成品=已完工→不是广义在产品 D"等待返修的废品"虽然叫废品，但在修好前算广义在产品
9 D 意外灾害→营业外支出 非常损失（天灾人祸）=营业外支出。管理不善=管理费用 灾害类型决定科目——天灾=营业外，人祸=管理
10 B 盘盈冲减管理费用 在产品盘盈→冲减管理费用。盘亏管理原因的→增加管理费用 盘盈贷记管理费用（减少），和现金盘盈记营业外收入不一样

计算题答案

题1： - 材料约当产量 = 200（一次投料→100%）；材料总约当 = 800+200 = 1,000 - 加工约当产量 = 200×50% = 100；加工总约当 = 800+100 = 900 - 材料分配率 = 96,000÷1,000 = 96；人工分配率 = 24,000÷900 ≈ 26.67；制造费分配率 = 12,000÷900 ≈ 13.33 - 完工成本 = 800×(96+26.67+13.33) = 108,800元 - 在产品成本 = (200×96)+(100×40) = 19,200+4,000 = 23,200元

题2： - 加工程度：第一道=(30×50%)/60=25%；第二道=(30+20×50%)/60≈66.67%；第三道=(30+20+10×50%)/60≈91.67% - 约当产量 = 50×25%+80×66.67%+40×91.67% = 12.5+53.33+36.67 = 102.5 - 分配率 = 38,500÷(500+102.5) = 63.90元/件 - 完工 = 500×63.90 = 31,950元；在产品 = 102.5×63.90 = 6,550元

题3（定额成本法）： - 在产品定额成本 = 材料100×100 + 加工(30+20)×100×60% = 10,000 + 3,000 = 13,000元 - 完工成本 = (55,000+18,000+10,000) - 13,000 = 83,000 - 13,000 = 70,000元 - 坑：材料一次投料→在产品材料按100%算定额；加工费按加工程度60%

题4（定额比例法）： - 材料：完工定额=400×100=40,000, 在产品定额=100×100=10,000 - 材料分配率 = 55,000÷50,000 = 1.10 - 完工材料 = 40,000×1.10 = 44,000；在产品材料 = 10,000×1.10 = 11,000 - 加工费：完工定额工时=400×(30+20)=20,000, 在产品定额工时=100×60%×50=3,000 - 加工分配率 = 28,000÷23,000 ≈ 1.2174 - 完工加工 = 20,000×1.2174=24,348；在产品加工=3,000×1.2174=3,652 - 完工总成本 = 44,000+24,348 = 68,348元；在产品总成本 = 11,000+3,652 = 14,652元 - 对比题3：定额成本法完工70,000 > 定额比例法68,348 → 因为定额成本法把有利差异全给了完工

题5：❌ 错误。 正确公式：某道工序加工程度 = （前面各工序工时定额之和 + 本工序工时定额×50%）/ 产品工时定额。 错误在于把"前面全額"和"本工序×50%"的位置写反了。

八、防坑预警——约当产量法四大致命陷阱

❌ 学生常犯 ✅ 正确做法
陷阱1：材料约当产量=加工约当产量 分别计算！投料方式决定材料约当产量，加工程度决定加工约当产量
陷阱2：加工程度公式=本工序全額+前面×50% 前面全額+本工序×50%，因为前面已完成、本道进行中
陷阱3：定额成本法适用于在产品变化大的情况 变化大→完工成本可能为负→必须改用定额比例法
陷阱4：一次投料→投料程度按加工程度算 一次投料→投料程度=100%，不用约当，直接用实际数量
陷阱5：分工序一次投料，投料程度用"前面累计×50%" 每道工序开始时一次投入→进入该工序时材料已全额投入→投料程度=到本工序为止的累计定额/总定额，本工序不乘50%
