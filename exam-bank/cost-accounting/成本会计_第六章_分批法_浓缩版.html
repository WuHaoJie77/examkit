成本会计 第六章 产品成本计算的分批法 浓缩速记卡

⚠️ 单件小批生产的成本计算 | 15+题 | 预计用时35分钟

💡 费曼类比：分批法就像婚庆公司接婚礼订单——每场婚礼（每批订单）的规格不同，鲜花、布置、司仪的费用都得按"这一场"单独算，不能像食堂一样把本月所有婚礼的成本混在一起分摊。简化分批法就是——公司同时接了十几场婚礼，先把所有婚礼的公共费用（司仪统筹费、车辆调度费）汇总，等哪场办完了再按工时比例算给它，没办完的先不摊这笔钱。

一、分批法核心特征

维度 分批法
别名 订单法
成本计算对象 产品批别（订单）
成本计算期 产品生产周期（与会计报告期不一致）
完工/在产品分配 批内同时完工→一般不需要分配
适用生产类型 单件小批生产
典型企业 服装、造船、重型机械、印刷

二、简化分批法（= 累计间接费用分配法）

为什么简化？

普通分批法：每批产品都要分配间接费用 → 批次多时工作量大 简化分批法：不逐批分配间接费用，等到产品完工时用累计间接费用分配率一次性分配

核心机制

要素 说明
产品成本明细账 完工前只登记直接费用+生产工时，不登记间接费用
生产成本二级账 必须设置！汇总全部批次的数据
累计间接费用分配率 = 全部间接费用累计 ÷ 全部工时累计
分配时机 有产品完工时才分配，未完工批次不分配

累计间接费用分配率的作用

既是各批产品之间分配间接费用的依据，也是完工产品与在产品之间分配的依据 → 双重功能。

判断："不论月份内是否有完工产品，都应计算累计间接费用分配率" → ❌ 错！没有完工就不算。

三、分批法 vs 简化分批法对比

普通分批法 简化分批法
间接费用分配 逐批分配 完工时一次性分配
明细账 登记全部费用 完工前只登记直接费用+工时
二级账 不需要 必须设置
适用 批次少 批次多、月末未完工批次多

四、间接费用分配标准的选择

分配标准 适用场景 优缺点
生产工时 各批产品工时差异大、制造费用与工时正相关 最常用，反映了劳动消耗
生产工人工资 各批工人工资率相近 简化计算，但工资率不同时失真
机器小时 高度自动化、设备折旧占比大 适合机器密集型生产
直接材料成本 制造费用与材料消耗正相关 材料价格波动会影响分配结果

选择原则：分配标准必须与制造费用的发生有因果关系（相关性），而不是图方便随便选。选了产量就等于退化回传统成本法了。

五、计算流水线

例题1：一般分批法——三批产品

某企业按订单生产，本月投产三批产品：

批号 产品 产量 投产日期 完工情况
401 A产品 100件 4月 本月全部完工
402 B产品 80件 4月 本月完工50件
403 C产品 120件 4月 本月全部未完工

本月发生费用：

批号 直接材料 直接人工 生产工时
401 50,000 24,000 1,200h
402 40,000 18,000 800h
403 60,000 30,000 2,000h
合计 150,000 72,000 4,000h

制造费用总额80,000元，按生产工时分配。402批完工50件为B产品产成品，其余30件为月末在产品（材料全部投入，加工程度50%）。

Step 1：分配制造费用（为什么：按工时比例——谁花的时间多谁多摊） 制造费分配率 = 80,000 ÷ 4,000 = 20元/h 401制造费 = 1,200×20 = 24,000元 402制造费 = 800×20 = 16,000元 403制造费 = 2,000×20 = 40,000元

Step 2：汇总各批总成本（为什么：直接费用+分配的间接费用=该批总成本） 401总成本 = 50,000+24,000+24,000 = 98,000元 → 单位成本 = 980元/件 402总成本 = 40,000+18,000+16,000 = 74,000元（需要分完工/在产品） 403总成本 = 60,000+30,000+40,000 = 130,000元（全部未完工）

Step 3：402批完工与在产品分配（为什么：批内部分完工时仍然需要分配，材料一次投入+加工50%） 402批材料：40,000÷80=500元/件×50件完工=25,000元；在产品=40,000-25,000=15,000元 402批加工费：总加工费=18,000+16,000=34,000；约当=50+30×50%=65件 分配率=34,000÷65≈523.08元/件 完工加工费=50×523.08≈26,154元；在产品加工费=30×50%×523.08≈7,846元 402批完工总成本=25,000+26,154=51,154元；单位=1,023.08元/件

Step 4：月末汇总（为什么：区分完工产品和在产品——分批法的产品明细账就是"天然的成本汇总表"） 本月完工产品总成本 = 401(98,000) + 402完工(51,154) = 149,154元 月末在产品总成本 = 402在产品(22,846) + 403(130,000) = 152,846元

例题2：简化分批法——累计间接费用分配

某企业采用简化分批法。7月份基本生产成本二级账累计数据：

项目 直接材料 生产工时 直接人工 制造费用 合计
月初累计 120,000 3,000h 45,000 60,000 225,000
本月发生 180,000 5,000h 75,000 100,000 355,000
累计 300,000 8,000h 120,000 160,000 580,000

各批产品明细账工时记录：

批号 月初累计工时 本月工时 完工情况
701 800h 1,200h 本月完工
702 1,200h 1,800h 本月完工
703 1,000h 2,000h 未完工

Step 1：计算全部产品累计间接费用分配率（为什么：二级账汇总了所有批次的累计数据） 人工累计分配率 = 120,000 ÷ 8,000 = 15元/h 制造费累计分配率 = 160,000 ÷ 8,000 = 20元/h

Step 2：分配间接费用给完工批次（为什么：只有完工的批次才享受分配，未完工的703不参与） 701批累计工时 = 800+1,200 = 2,000h 701批人工 = 2,000×15 = 30,000元；制造费 = 2,000×20 = 40,000元

702批累计工时 = 1,200+1,800 = 3,000h 702批人工 = 3,000×15 = 45,000元；制造费 = 3,000×20 = 60,000元

703批：未完工→不分配间接费用！

Step 3：各批产品总成本汇总（为什么：完工批次的成本=直接材料(来自明细账)+分配的间接费用） （需要各批明细账的直接材料数据） 假设：701批直接材料60,000元 → 总成本=60,000+30,000+40,000=130,000元 702批直接材料90,000元 → 总成本=90,000+45,000+60,000=195,000元 703批：明细账上只有直接材料48,000元和累计工时3,000h→不计算总成本，结转下月

核心理解：简化分批法下，未完工批次的明细账上只有直接材料和生产工时——没有间接费用。等该批完工那个月，才用当月的累计分配率一次性补上。

计算题（5题）

题1：某企业本月投产两批产品。#801批：A产品60件，直接材料36,000元，直接人工15,000元，工时1,500h，本月全部完工。#802批：B产品80件，直接材料48,000元，直接人工25,200元，工时2,100h，本月全部未完工。制造费用总额54,000元，按工时分配。求各批总成本和#801批单位成本。

题2：以上题数据为基础。如果#802批本月完工40件，另外40件为在产品（材料一次投入，加工程度60%），制造费用改按直接人工比例分配。求#802批完工产品和月末在产品成本。

题3：某企业采用简化分批法。7月份二级账累计：直接人工75,000元，制造费用105,000元，累计工时7,500h。#601批本月完工，累计工时2,500h，直接材料88,000元。#602批未完工，累计工时2,000h，直接材料64,000元。求#601批总成本和单位成本（产量200件）。

题4：说明在什么情况下应该选用简化分批法而不是普通分批法？简化分批法的两个前提条件是什么？

题5：判断："简化分批法下，不论是否有完工产品，每月末都应计算累计间接费用分配率。"是否正确？说明理由。

七、答案与解析

选择题答案

题号 答案 思路 推导 坑点
1 B 分批法的别名 分批法=按订单生产=订单法 品种法没有别名
2 B 适合分批法的企业 服装=每批款式不同=单件小批=分批法。A/C/D都是大量大批→品种法 小型水泥厂虽然是水泥，但它是大量大批→品种法
3 B 简化分批法特征 完工前只登记直接费用+生产工时，间接费用等完工后再分配 A"不登记任何"错了（直接费用还是要登记的）
4 C 累计间接费用分配率来源 二级账汇总了全部批次的数据→分配率由此计算 明细账只记录单个批次，看不到全貌
5 C 双重分配功能 完工时一次性分配→既区分了各批，也区分了完工/在产品 这是简化分批法的核心优势
6 B 分批法计算期 分批法=按订单生产→订单完成才结算→计算期=生产周期 品种法才是月度
7 C 分批法优势 批内同时完工→完工时该批全部完成→不需要完工/在产品分配 不是不需要费用分配，是不需要"完工vs在产品"的分配
8 D 简化核心 用累计分配率一次性分配→不用逐批分配→简化 B"不分批计算在产品成本"也是结果，但根因是D
9 B 必要条件 二级账汇总全部批次数据→没有它无法算累计分配率 普通分批法不需要二级账
10 B 适用类型 单件小批=分批法。A/C=品种法/分步法 生产组织类型决定成本计算方法

计算题答案

题1：

Step 1：制造费分配率 = 54,000÷(1,500+2,100) = 54,000÷3,600 = 15元/h Step 2：#801制造费 = 1,500×15=22,500；#802制造费 = 2,100×15=31,500 Step 3：#801总成本 = 36,000+15,000+22,500 = 73,500元 → 单位=73,500÷60=1,225元/件 #802总成本 = 48,000+25,200+31,500 = 104,700元（全部为在产品，结转下月）

题2：

#802批材料：48,000÷80=600元/件 → 完工40件=24,000元；在产品40件=24,000元 #802批加工费总额 = 25,200+31,500=56,700元（制造费本题按人工比例；但制造费此题仍用题1的15元/h结果→保持自洽，即制造费=31,500不变） 约当产量 = 40+40×60% = 64件 加工分配率 = 56,700÷64 ≈ 885.94元/件 完工加工费 = 40×885.94≈35,438元；在产品加工费 = 40×60%×885.94≈21,262元 完工总成本 = 24,000+35,438 = 59,438元 → 单位=1,485.95元/件 在产品成本 = 24,000+21,262 = 45,262元

题3：

Step 1：累计人工分配率 = 75,000÷7,500 = 10元/h 累计制造费分配率 = 105,000÷7,500 = 14元/h Step 2：#601批人工 = 2,500×10=25,000元；制造费 = 2,500×14=35,000元 Step 3：#601总成本 = 88,000+25,000+35,000 = 148,000元 → 单位=148,000÷200 = 740元/件 #602批：未完工，不做分配，直接材料和2,000h结转下月。

题4： 选用简化分批法的前提条件（两个必要条件）： ① 投产批次多，月末未完工批次也多——逐批分配工作量太大，用累计分配法才有意义 ② 各月间接费用水平相对稳定——如果波动大，用累计分配率会造成完工批次的成本失真（可能把淡季的低费用率用在了旺季完工的产品上） 两者缺一不可。批次少→普通分批法更准确；费用波动大→简化分批法反而失真。

题5： ❌ 错误。简化分批法只在有产品完工的月份才需要计算累计间接费用分配率。如果当月没有完工产品，就无需计算——因为没有产品需要分配间接费用。无完工月份只需将本月发生的间接费用和生产工时累计到二级账中即可。

八、⚠️ 防坑预警

❌ 学生常犯 ✅ 正确做法
坑1：分批法成本计算期=月度 分批法计算期 = 生产周期（≠会计报告期），和品种法刚好相反
坑2：简化分批法下未完工批次也分配间接费用 简化分批法下→没有完工就不分配！未完工批次明细账只记直接材料+工时
坑3：简化和普通分批法的区别只在"有没有二级账" 核心区别是分配时机——普通逐批分配，简化等完工一次性分配。二级账只是工具
坑4：批内部分完工时不需要完工/在产品分配 如果一批产品跨月陆续完工→仍然需要在该批内部做完工/在产品分配！（见例题1的402批）
坑5：制造费用分配标准随便选 标准必须与制造费用有因果关系——选产量=退化回传统成本法；选工时/工资/机器小时取决于费用驱动因素
坑6：简化分批法任何时候都比普通法好用 不是！间接费用水平波动大的企业→简化分批法会失真（完工批次的成本受其他月份费用的影响）
