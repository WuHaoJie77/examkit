成本会计 第五章 产品成本计算的品种法 浓缩速记卡

⚠️ 三种基本方法中最基础的一种 | 15+题 | 预计用时35分钟

💡 费曼类比：品种法就像食堂做盒饭——每天生产几百份同样的盒饭（大批量、标准化、单一品种），每份成本完全一样，没人关心"第123号盒饭用了多少材料"。月底算总账：本月买菜花了多少钱（直接材料）？厨师工资多少（直接人工）？燃气水电多少（制造费用）？三项加总÷本月盒饭总数=每份盒饭的成本。如果月底还剩半成品食材没做完，按加工程度折算出"半盒饭"的价值（完工/在产品分配）。品种法的灵魂就是「按月算总账，按品种摊成本」——不搞定制化订单（那是分批法的活），也不分步骤核算（那是分步法的活），是最简单直接的大批量平均法。

一、品种法核心特征

维度 品种法
成本计算对象 产品品种
成本计算期 月度（与会计报告期一致）
与生产周期关系 不一致（按月算，不按生产周期）
是否需分配完工/在产品 一般需要（除非无在产品或很少）
明细账设置 按产品品种设
地位 最基本的成本计算方法

判断："品种法的成本计算期与生产周期一致" → ❌ 错！与会计报告期（月度）一致，与生产周期不一致。

二、适用范围

适用 不适用
✅ 大量大批单步骤生产（发电、供水、采掘） ❌ 单件小批生产（→分批法）
✅ 管理上不要求分步的大量大批多步骤生产（小型水泥厂、砖瓦厂、糖果厂） ❌ 管理上要求分步的多步骤生产（→分步法）

判断："品种法只适用于单步骤生产" → ❌ 错！管理上不要求分步的多步骤生产也可以用。

三、简化品种法

当企业产品单一、无在产品或很少→不计算在产品成本→简化品种法。

简化品种法 = 品种法 + 不计算在产品成本法。

四、三种基本方法对比（必背框架）

品种法 分批法 分步法
成本对象 品种 批别/订单 步骤+品种
成本计算期 月度 生产周期 月度
适用生产类型 大量大批 单件小批 大量大批多步骤
典型企业 发电/供水/采掘 服装/造船/重型机械 纺织/冶金/汽车
生产费用在完工/在产品间分配 一般需要 一般不需要（批内同时完工） 需要（广义在产品）

五、品种法完整计算流水线

品种法的计算流程就是成本会计的"标准流水线"：

要素费用分配 → 辅助生产分配 → 制造费用分配 → 完工与在产品分配

例题1：完整品种法（单品种+有在产品）

某企业生产甲产品，大量大批单步骤。本月产量：投产1,200件，完工1,000件，月末在产品200件。原材料一次投入，在产品加工程度50%。

月初在产品成本 + 本月生产费用：

项目 直接材料 直接人工 制造费用 合计
月初在产品 12,000 4,000 3,000 19,000
本月发生 108,000 46,000 37,000 191,000
合计 120,000 50,000 40,000 210,000

Step 1：计算材料约当产量（为什么：一次投料→投料程度100%→在产品材料约当=实际数量） 材料约当产量 = 200 × 100% = 200件 材料总约当产量 = 1,000 + 200 = 1,200件

Step 2：计算加工费约当产量（为什么：加工程度50%→人工和制造费用按50%折算） 加工约当产量 = 200 × 50% = 100件 加工总约当产量 = 1,000 + 100 = 1,100件

Step 3：计算各项目分配率（为什么：总成本÷总约当产量=单位分配率） 直接材料分配率 = 120,000 ÷ 1,200 = 100元/件 直接人工分配率 = 50,000 ÷ 1,100 ≈ 45.45元/件 制造费用分配率 = 40,000 ÷ 1,100 ≈ 36.36元/件

Step 4：分配完工产品和在产品成本（为什么：完工产品按实际产量×分配率，在产品=总成本-完工成本） 完工产品成本 = 1,000 × (100 + 45.45 + 36.36) = 1,000 × 181.81 = 181,810元 在产品成本 = 210,000 - 181,810 = 28,190元

验证：在产品材料 = 200×100 = 20,000；加工费 = 100×(45.45+36.36) = 8,190 → 20,000+8,190 = 28,190 ✓

单位完工成本 = 181,810 ÷ 1,000 = 181.81元/件

例题2：多品种品种法

某企业生产甲、乙两种产品，采用品种法计算成本。本月发生：

材料费用（按定额耗用量分配）：甲定额100kg/件、乙定额60kg/件。甲产量500件、乙产量800件。材料实际总成本128,000元。

人工费用（按实际工时分配）：甲耗用2,000h，乙耗用3,000h。工资总额75,000元。

制造费用（按人工工时分配）：总额60,000元。甲机器小时800h，乙机器小时1,200h。注意：制造费用用人工工时分配，不用机器小时（题目已明确）。

Step 1：材料费用分配（为什么：定额耗用量比例法——材料按"应该用多少"来分） 甲定额总量 = 500×100 = 50,000kg；乙定额总量 = 800×60 = 48,000kg 定额合计 = 50,000+48,000 = 98,000kg 材料分配率 = 128,000 ÷ 98,000 ≈ 1.3061元/kg 甲材料费 = 50,000×1.3061 = 65,306元；乙材料费 = 48,000×1.3061 ≈ 62,694元

Step 2：人工费用分配（为什么：工时比例法——谁花的时间多谁多摊） 工时合计 = 2,000+3,000 = 5,000h 人工分配率 = 75,000 ÷ 5,000 = 15元/h 甲人工费 = 2,000×15 = 30,000元；乙人工费 = 3,000×15 = 45,000元

Step 3：制造费用分配（为什么：按人工工时——和人工消耗正相关） 制造费分配率 = 60,000 ÷ 5,000 = 12元/h 甲制造费 = 2,000×12 = 24,000元；乙制造费 = 3,000×12 = 36,000元

Step 4：汇总产品成本 甲总成本 = 65,306+30,000+24,000 = 119,306元 → 单位成本 = 119,306÷500 ≈ 238.61元/件 乙总成本 = 62,694+45,000+36,000 = 143,694元 → 单位成本 = 143,694÷800 ≈ 179.62元/件

计算题（5题）

题1：某企业用品种法计算甲产品成本。本月产量：完工900件，在产品100件（完工程度60%，材料一次投入）。月初+本月：材料105,000元，人工48,500元，制造费用29,100元。求完工产品总成本和单位成本。

题2：某企业生产甲、乙两种产品。材料按定额耗用量分配：甲定额80元/件×400件，乙定额50元/件×600件，材料总成本74,400元。人工按工时：甲1,200h/乙1,800h，人工总成本45,000元。制造费用按人工工时：总额36,000元。求甲、乙总成本和单位成本。

题3：判断："品种法只适用于单步骤生产。"说明理由并给出反例。

题4：品种法的成本计算流程包括哪几个主要步骤？每一步的任务是什么？

题5：对比品种法、分批法、分步法在成本计算期和完工/在产品分配上的区别。

七、答案与解析

选择题答案

题号 答案 思路 推导 坑点
1 A 基本方法排名 品种法是最基础的方法，分步法是品种法的多次连接，分批法是品种法按批别应用 分类法/定额法是辅助方法，不是基本方法
2 B 核心特征 品种法=按品种算成本→对象=品种 不要和分批法（批别）、分步法（步骤）搞混
3 C 计算时间 品种法按月算→成本计算期=月份→与会计报告期一致 不是按生产周期（分批法的特征）
4 A 明细账结构 品种法→按品种设明细账 分批法按批别，分步法按步骤
5 A 成本计算第一步 先确定算谁的成本（对象）→再定什么时候算（计算期）→再选方法 逻辑顺序：对象→期→方法→分配
6 C 典型企业识别 发电=大量大批单步骤=品种法。A/B/D都是单件小批→分批法 服装=分批（每批款式不同），发电=品种（产品单一）
7 A 简化品种法条件 产品单一+无在产品→不用分配完工/在产品→简化品种法 简化的是"完工/在产品分配"这一步
8 B 品种法特征 按月算成本←→生产周期可能跨月→不一致 分批法的成本计算期才与生产周期一致
9 C 基本方法vs辅助方法 基本方法=品种/分批/分步。分类法是辅助方法 分类法不是基本方法，不单独使用
10 A 品种法的扩展适用 多步骤但不要求分步→可以按品种法处理 这是品种法适用范围的"或者"条款

计算题答案

题1：

Step 1：材料约当产量（一次投料→100%）→ 材料总约当 = 900+100 = 1,000件 Step 2：加工约当产量（60%）→ 加工总约当 = 900+100×0.6 = 960件 Step 3：材料分配率 = 105,000÷1,000=105；人工分配率=48,500÷960≈50.52；制造费分配率=29,100÷960≈30.31 Step 4：完工=900×(105+50.52+30.31)=900×185.83=167,247元；单位成本=185.83元/件 验证：在产品=105,000+48,500+29,100-167,247=15,353元 ✓

题2：

材料：甲定额=400×80=32,000；乙定额=600×50=30,000；合计62,000 分配率=74,400÷62,000=1.2；甲材料=32,000×1.2=38,400；乙=30,000×1.2=36,000 人工：工时合计1,200+1,800=3,000h；分配率=45,000÷3,000=15元/h 甲人工=1,200×15=18,000；乙=1,800×15=27,000 制造费：分配率=36,000÷3,000=12元/h 甲制造费=1,200×12=14,400；乙=1,800×12=21,600 汇总：甲总成本=38,400+18,000+14,400=70,800元→单位=177元/件 乙总成本=36,000+27,000+21,600=84,600元→单位=141元/件

题3： ❌ 错误。品种法还适用于"管理上不要求分步计算成本的大量大批多步骤生产"。反例：小型水泥厂是多步骤生产（破碎→粉磨→烧成），但如果管理上不要求分步核算，就可以用品种法。关键不是工艺有几个步骤，而是管理上是否要求分步。

题4： 品种法计算流程四步： ① 要素费用分配：将直接材料、直接人工等按受益对象分配到各品种 ② 辅助生产费用分配：将供水、供电、修理等辅助车间的费用分配到基本生产车间（无辅助生产时可跳过） ③ 制造费用分配：将各车间的制造费用按适当标准（工时/工资等）分配到各品种 ④ 完工与在产品分配：将每个品种的总生产费用在完工产品和月末在产品之间分配，确定完工产品总成本和单位成本

题5：

品种法 分批法 分步法
成本计算期 月度（=会计报告期） 生产周期（≠会计报告期） 月度（=会计报告期）
完工/在产品分配 一般需要 一般不需要（批内同时完工） 需要（广义在产品）

八、⚠️ 防坑预警

❌ 学生常犯 ✅ 正确做法
坑1：品种法成本计算期=生产周期 品种法按月算→成本计算期=月度，与会计报告期一致
坑2：品种法只适用于单步骤生产 管理上不要求分步的多步骤生产也可以用品种法（如小型水泥厂）
坑3：多品种品种法每种产品用不同分配标准 同一费用项目对所有产品用同一种分配标准（如材料全按定额比例、人工全按工时）
坑4：品种法不需要完工/在产品分配 品种法一般需要分配！只有在无在产品（或量很少）时才用简化品种法
坑5：品种法下辅助生产费用直接计入产品成本 辅助生产费用先在各受益车间间分配→计入各车间制造费用→再分配到产品
坑6：三种基本方法按复杂程度排序 不是！分类标准是成本计算对象（品种/批别/步骤）不是复杂度
