成本会计 第二章 成本核算的基本原理 浓缩速记卡

费用分类体系 + 成本核算框架 | 21题 | 预计用时35分钟

💡 费曼类比：成本核算就像给一群人分账单——先搞清楚这顿饭花了什么（要素费用），再把每道菜归到点了它的人头上（成本项目），最后算出每个人该付多少钱（完工产品成本）。有些人直接点了菜（直接计入），有些人AA（间接计入），跨月的团购券还要分摊（跨期费用）。

一、核心概念对比表

对比1：产品成本项目 vs 要素费用（最核心！）

产品成本项目 要素费用
分类标准 按经济用途（钱花在哪了） 按经济内容/性质（花的是什么钱）
包含内容 直接材料、直接人工、制造费用、废品损失 外购材料、外购动力、工资、折旧费、利息等
是否计入产品成本 ✅ 全部计入 部分计入（有些入期间费用）
关系 要素费用是"原材料"，经过归集分配后形成成本项目

记忆口诀：要素是"什么钱"，项目是"干什么用的钱"。

判断："要素费用是生产费用按经济用途的分类" → ❌ 错！是按经济内容分类。

对比2：直接计入费用 vs 间接计入费用

直接计入费用 间接计入费用
归属方式 能直接判定属于哪个产品 需要分配才能归到各产品
典型例子 甲产品专用材料、甲产品的生产工人工资 几种产品共同的原材料、车间管理人员工资
判断标准 一发生就知道归谁 需要按标准分配

判断坑：生产车间的机物料消耗 → 间接计入（不能直接归属到具体产品），辅助车间生产工人薪酬 → 如果只生产一种产品就是直接计入，多种产品就是间接计入。

对比3：四大费用界限

界限 划分对象 遵循原则 违反后果
成本费用 vs 期间费用 生产成本和三大期间费用 — 产品成本计算错误
本期费用 vs 以后期间费用 跨期摊提 权责发生制 各期成本不实
各种产品之间 不同产品的成本 受益原则 各产品成本不准确
完工产品 vs 在产品 同一产品完工和未完工部分 — 完工产品单位成本失真

跨期费用摊提 → 对应第二个界限（本期/以后期间），用的是权责发生制，不是划分各种产品之间的界限。

对比4：生产成本账户体系

账户 借方（增加） 贷方（减少） 月末余额
生产成本——基本生产成本 直接材料、直接人工、转入的制造费用 完工转出至库存商品 在产品成本
生产成本——辅助生产成本 辅助车间发生的各项费用 分配给各受益对象 一般无余额
制造费用 各项间接生产费用 分配转入生产成本 一般无余额（季节性企业除外）

二、综合题精讲：李明公司（本章核心大题）

题目还原

李明公司第一年生产A产品，年末存货：原材料92,000元、在产品63,000元、产成品1,200个177,000元。年初无存货。

李明自己计算的利润：

销售净额                1,221,200
已售产品成本            1,327,200  ← 含原材料362K+工资220K+制造费用340K
销售费用                  141,200
管理费用                  264,000
净亏损                    106,000

李明的错误在哪？

❌ 他把全年发生的全部生产成本当成了已售产品成本！

全年生产成本 = 362,000 + 220,000 + 340,000 = 922,000元（这是全年投入的生产费用，不是已售产品成本）

实际上，这922,000元去向有三处： - 还在仓库里的原材料：92,000元（没用到生产上） - 还在车间没做完的在产品：63,000元 - 已完工但没卖出去的产成品：177,000元（1,200个） - 真正卖出去的4,000个产品的成本：需要计算

✅ 正确解法（Step by Step）

Step 1：算本期投入的材料费用 期初材料0 + 本期购入362,000 - 期末材料92,000 = 本期耗用材料 270,000元 注意：买的不等于用的！买的362K，用了270K，剩92K在仓库。

Step 2：算本期完工产品成本 期初在产品0 + 本期投入(270,000 + 220,000 + 340,000) - 期末在产品63,000 = 0 + 830,000 - 63,000 = 完工产品成本 767,000元 本期投入 = 耗用材料270K + 直接人工220K + 制造费用340K = 830K

Step 3：算单位完工成本 完工总产量 = 已售4,000 + 期末库存1,200 = 5,200个 单位成本 = 767,000 ÷ 5,200 ≈ 147.50元/个 李明的"竞争对手成本175元"比他算的331.80元低，但比他实际的147.50元还高！他实际上有成本优势！

Step 4：算已售产品成本 已售产品成本 = 147.50 × 4,000 = 590,000元

Step 5：算正确利润 销售收入 1,221,200 - 已售成本 590,000 - 销售费用 141,200 - 管理费用 264,000 = 利润总额 226,000元 所得税 25% = 56,500 净利润 = 169,500元（盈利！不是亏损！）

坑点总结

李明的错误 正确做法
把"购买原材料"362K全算进成本 只算实际耗用的270K（买的≠用的）
忘了期末在产品63K 要从投入中减掉（没完工的不能算进完工成本）
忘了期末产成品177K 已售成本≠完工成本（完工5,200个，只卖了4,000个）
得出的"平均单位成本331.80元" 实际单位成本147.50元（他把所有费用÷4,000，没减存货）

题3：分别说明成本核算需要正确划分的四个费用界限，并各举一例。

题4：判断："只要是发生在生产车间的费用，都属于直接计入费用。"是否正确？说明理由并举反例。

题5（综合）：某企业期初材料10,000元，本月购入50,000元，期末盘点材料8,000元。期初在产品6,000元，期末在产品4,000元。本月直接人工15,000元，制造费用9,000元。本月投产全部完工，完工产品10,000件，售出8,000件。要求： （1）计算本月耗用材料费用 （2）计算本月完工产品总成本和单位成本 （3）计算已售产品成本和期末库存商品成本

四、答案与解析

选择题答案

题号 答案 思路 推导 坑点
1 C 考成本项目的构成 成本项目=直接材料+直接人工+制造费用+废品损失。A/B/D都是要素费用（按经济内容分），只有C制造费用是成本项目 制造费用属于成本项目，不要被"费"字骗到——会计里"制造费用"是一个成本项目名
2 C 考要素费用的构成 要素费用按经济内容分：外购材料/动力/工资/折旧/利息等。折旧费用是要素费用。A/B/D都是成本项目 直接材料是成本项目，但"外购材料"是要素——一个是从用途看，一个是从来源看
3 C 区分生产成本vs管理费用 厂部行政人员→管理费用（期间费用），不计入产品成本。A/B/D都和生产相关→计入成本 D"季节性停工损失"是国家允许计入制造费用的特殊项目，不要看到"停工"就觉得不该计入
4 D 制造费用的范围 制造费用=生产车间间接费用。D车间固定资产折旧→间接生产费用→制造费用。A/B/C都不在制造费用范围（A财务费用/B管理费用/C销售费用） B职工教育经费分情况——车间人员的是制造费用，但题目没说是车间的→默认是管理费用
5 C 直接计入vs间接计入 C"甲产品"的生产工人薪酬→明确归属→直接计入。A车间机物料→多个产品共用→间接；B辅助车间→可能需分配→间接 关键看"能否无需分配直接归属"——只要标的明确就是直接，跟金额大小无关
6 C 成本核算四原则 合法性+实际成本计价+权责发生制+一贯性。收付实现制不是成本核算原则 权责发生制是，收付实现制不是——两个容易记混
7 B 资本性支出 专利权→多个期间受益→资本性支出。A/D是收益性支出（当期消耗），C是营业外支出 不是按金额大小判，是按受益期——5块钱的文具也是收益性支出
8 C 间接计入费用 多种产品共同耗用→必须分配→间接计入。A/B专属于特定产品→直接计入。D不是生产成本 联产品耗用的原材料虽然是多个产品但按产出比例直接分配→有的是直接计入
9 B 生产成本明细账结构 按成本计算对象设明细账，账内按成本项目（直接材料/直接人工/制造费用）分专栏。不是按费用要素或费用性质 明细账里填的是"这个产品花了多少材料、多少人工、多少制造费"——这就是成本项目
10 B 跨期费用的目的 跨期费用=跨月/跨年的费用→摊提=划清本期和以后期间的界限 A是成本vs期间费用的界限，跨期是在成本内部划时间界限
11 B 生产成本账户结构 借方=增加=生产过程中发生的料/工/费。A是贷方（完工转出），C/D都不是借方内容 生产成本借方是"流入"（投入生产），贷方是"流出"（完工转走）
12 C 要素费用的本质 折旧费用=按经济内容分=要素费用。A错（要素≠成本项目）；B错（按经济内容分）；D错（要素费用部分入期间费用） 要素费用中只有用于生产的部分才计入产品成本，其他进期间费用
13 B 辅助生产成本余额 辅助生产车间费用期末已全部分配出去→一般无余额 有例外（如对外提供劳务的辅助车间可能有余额），但考试默认无余额
14 B 制造费用余额例外 季节性生产企业→淡季生产旺季销售→期末可能有余额。一般企业期末制造费用分配完毕→无余额 这是考试高频题，记住"季节性"三个字
15 B 不同费用界限对应不同原则 各种产品之间→按谁受益谁承担→受益原则。跨期费用→权责发生制。不要混淆 权责发生制对应"本期/以后期间"界限，受益原则对应"各产品之间"界限

大题参考答案

题1： - 本期投入 = 60,000 + 30,000 + 20,000 = 110,000元 - 完工产品成本 = 0 + 110,000 - 5,000 = 105,000元 - 已售产品成本 = 105,000元（全部售出） - 管理费用15,000/销售费用8,000/财务费用2,000→期间费用，不计入产品成本 - 坑：制造费用20,000要计入，但管理费用不要计入

题2： - 要素费用按经济内容分类：外购材料、外购动力、职工薪酬、折旧费等 - 产品成本项目按经济用途分类：直接材料、直接人工、制造费用 - 关系：要素费用是"原材料"→经过归集分配→形成成本项目。比如"外购材料"这个要素费用，生产用的变成"直接材料"成本项目，管理用的变成"管理费用" - 坑：不是一一对应关系，一个要素费用可能拆到多个成本项目

题3：

界限 例子
成本费用vs期间费用 车间水电费(→成本) vs 厂部水电费(→管理费用)
本期vs以后期间 预付半年房租→按月摊销
各产品之间 A/B产品共同耗用材料→按定额分配
完工vs在产品 月末需用约当产量法划分

题4：❌ 错误。

反例：生产车间的机物料消耗→发生在生产车间但不属于直接计入费用（多种产品共同受益，需要分配）。直接计入费用的标准是"能直接判定归属"，不是按地点判断。

题5： 1. 耗用材料 = 10,000 + 50,000 - 8,000 = 52,000元 2. 本期投入 = 52,000 + 15,000 + 9,000 = 76,000元；完工成本 = 6,000 + 76,000 - 4,000 = 78,000元；单位成本 = 78,000 ÷ 10,000 = 7.80元/件 3. 已售成本 = 7.80 × 8,000 = 62,400元；期末库存 = 7.80 × 2,000 = 15,600元

五、防坑预警

❌ 学生常犯 ✅ 正确做法
要素费用=成本项目 要素按经济内容分，成本项目按经济用途分
"制造费用"是期间费用 制造费用是成本项目，最终计入产品成本
全部生产成本=已售产品成本 已售成本≠生产成本，要减去期末存货
购买的材料=耗用的材料 耗用=期初+购入-期末
发生在车间=直接计入 看能不能直接归属，不看地点
划分各产品界限用权责发生制 各产品之间用受益原则，跨期才用权责发生制
