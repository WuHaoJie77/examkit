51|## 自己部署

### Docker 一键部署（推荐）

零环境依赖，一条命令搞定：

```bash
docker compose up -d
```

访问 http://localhost:8898

- 评论数据保存在 `data/comments.db`
- PDF 缓存在 `data/pdf_cache/`
- 前端修改后 `docker compose -f docker-compose.dev.yml up` 即时生效，无需重建


52|
53|### 前端（纯静态）
54|直接用浏览器打开 `exam-bank/index.html`，或放到任意静态服务器上。
55|
56|### 后端（评论区 + PDF 下载）
57|后端代码见 `backend/app.py`，基于 FastAPI + weasyprint。
58|
59|```bash
60|cd backend
61|pip install fastapi uvicorn weasyprint
62|# 修改 app.py 里的 ADMIN_PASS 和路径
63|uvicorn app:app --host 0.0.0.0 --port 8890
64|```
65|
66|配合 Nginx 反向代理（参考 `backend/nginx.conf`）即可完整运行。
