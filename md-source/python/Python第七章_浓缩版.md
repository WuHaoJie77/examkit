## 一、程序三种基本结构

```
顺序结构 → 分支结构 → 循环结构
(逐行执行)  (条件选择)  (重复执行)
```

| 结构 | 特点 | 流程图形状 |
|------|------|------------|
| **顺序** | 按语句顺序逐条执行，每条都执行 | 矩形框（处理） |
| **分支** | 根据条件选择执行路径 | 菱形框（判断） |
| **循环** | 重复执行一组语句 | 菱形+流向线组合 |

> 递归结构**不是**基本结构。任何程序都包含顺序结构。

---

## 二、流程图符号

| 符号 | 含义 |
|------|------|
| 椭圆形/圆角矩形 | 起止框 |
| **矩形** | **处理框** |
| **菱形** | **判断框** |
| **平行四边形** | **输入/输出框** |
| 箭头线 | 流向线 |

> 没有"循环框"这个基本元素。循环是判断+流向线组合实现的。

## 三、关系运算符（比较运算）

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `==` | 等于 | `3 == 3` → True |
| `!=` | 不等于 | `3 != 5` → True |
| `>` | 大于 | `5 > 3` → True |
| `<` | 小于 | `3 < 5` → True |
| `>=` | 大于等于 | `5 >= 5` → True |
| `<=` | 小于等于 | `3 <= 5` → True |
| `in` | 包含 | `'ab' in 'abc'` → True |

### 3.1 字符串比较

按**Unicode编码**逐字符比较，短串是前缀时短串小：

```python
"PYTHON" > "python"     # False (大写字母编码 < 小写)
"apple" > "banana"      # False ('a'=97 < 'b'=98)
"apple" > "app"         # True (前缀相同，长的更大)
"apple" == "Apple"      # False ('a'≠'A')
"123" > "23"            # False ('1' < '2'，逐字比较！)
```

### 3.2 链式比较

```python
1 < 3 < 5       # True (等价 1<3 and 3<5)
2 > 3 > 1       # False (2>3 is False，后面短路)
3 <= 5 >= 4     # True (3<=5 and 5>=4)
```

### 3.3 常见条件表达式

```python
# 判断奇数
x % 2 == 1                    # ✅ 正确
x % 2 = 1                     # ❌ = 是赋值

# 判断整除（能被3整除）
x % 3 == 0                    # ✅ 正确
x // 3 == 0                   # ❌ 只在 x<3 时成立

# 判断三位整数
x >= 100 and x <= 999         # ✅
len(str(x)) == 3              # ✅
x // 100 != 0 and x // 1000 == 0  # ✅

# 判断闰年
(year % 4 == 0 and year % 100 != 0) or year % 400 == 0

# 判断三角形（三边a,b,c）
a + b > c and a + c > b and b + c > a

# 判断等腰三角形
a == b or b == c or a == c    # ✅ 用 == 不是 =

# 判断字符是否数字
"0" <= x <= "9"               # ✅ 字符串比较
```

## 四、逻辑运算符

> **🧠 费曼：and=并且，or=或者，not=不是。** 你妈说："做完作业并且洗完碗才能打游戏"——`and`：两个都完成才行。你爸说："扫完地或者倒完垃圾就可以看电视"——`or`：完成一个就行。`not`就是否定：`not 下雨`="没下雨"。短路规则：and遇到第一个False就懒得往后看了，or遇到第一个True就停了——计算机跟你一样懒。

### 4.1 优先级（从高到低）

```
not → and → or
```

| 运算符 | 含义 | 规则 |
|--------|------|------|
| `not` | 非 | 取反 |
| `and` | 与 | 全True才True |
| `or` | 或 | 有一个True就True |

### 4.2 短路求值

```python
False and anything    # False（and 遇 False 就停）
True or anything      # True（or 遇 True 就停）
3 > 5 and a > 3       # False（左边假，右边不执行）
```

### 4.3 布尔值运算

```python
True + 1        # 2 (True=1)
False + 1       # 1 (False=0)
True * 3        # 3
False - 1       # -1

True == 1       # True
False == 0      # True
```

### 4.4 逻辑运算求值步骤

```python
# 优先级: not > and > or
True and False or True          # False or True = True
True and (False or True)        # True and True = True
not True and False or True      # False and False or True = False or True = True

# 算术 > 比较 > not > and > or
5 + 3 > 6 * 2 - 4               # 8 > 8 = False
5 + (3 > 6) * 2 - 4             # 5 + 0*2 - 4 = 1
```

## 五、input() 的类型陷阱

```python
a = input()          # 用户输入 56
a == 56              # False！ a是"56"(str)，56是int
a == '56'            # True
a != 56              # True

# 正确比较数值
int(a) == 56         # True
eval(a) == 56        # True
```

## 六、综合表达式速算

```python
# 括号改变逻辑
a, b, c = 3, 5, 2
a < b or b > c and a == c       # True or False and False → True or False = True
(a < b or b > c) and a == c     # (True or False) and False → True and False = False

# 算术 + 比较 + 逻辑混合
3**2 + 4**2 == 5**2              # 9+16==25 → True
3**2 + (4**2 == 5**2)            # 9 + False → 9 + 0 = 9
(3**2 + 4**2) == 5**2            # 25 == 25 → True
```
