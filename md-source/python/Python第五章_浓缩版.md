## 一、字符串界定符

> **🧠 费曼：字符串界定符 = 引号是"袋子"，把字符装进去。** 单引号是一个小袋子，双引号是一个大袋子，三引号是一个超大垃圾袋——什么都能往里塞，换行也不怕。如果袋子里本身就有引号怎么办？你用不同的袋子装（双引号袋子里可以放单引号），或者在引号前加个反斜杠`\`表示"别把我当袋子口，我就是个普通字符"。

| 方式 | 示例 | 适用场景 |
|------|------|----------|
| 单引号 | `'hello'` | 内部不含单引号 |
| 双引号 | `"hello"` | 内部含单引号 `"I'm"` |
| 三单引号 | `'''...'''` | 多行 / 含两种引号 |
| 三双引号 | `"""..."""` | 多行 / 含两种引号 |

**空字符串：** `''` 或 `""`（中间不能有空格，`" "` 不是空串）

### 1.1 引号嵌套规则

```python
s = 'He said "Hello"'        # ✅ 双引号在单引号内
s = "I'm fine"                # ✅ 单引号在双引号内
s = 'I\'m a student'          # ✅ 转义单引号
s = 'I'm a student'           # ❌ 单引号未转义，语法错误
s = "He said \"Hello\""       # ✅ 转义双引号
```

### 1.2 三引号 = 多行 + 引号自由

```python
s = '''你好！
你今天过得好吗？
要保重身体呀！'''              # ✅ 多行保留换行
s = '''He said "It's great!"''' # ✅ 同时含单双引号
```

**注意：** 三引号不只用于多行，单行也能用。单引号内不能直接手动换行。

### 1.3 转义字符

| 转义 | 含义 | 占位 |
|------|------|:--:|
| `\n` | 换行 | 1字符 |
| `\t` | 制表符 | 1字符 |
| `\\` | 反斜杠 | 1字符 |
| `\'` | 单引号 | 1字符 |
| `\"` | 双引号 | 1字符 |

```python
s = "python\n编程\t很\t容易\t学"
len(s)  # 16！
# python = 6, \n = 1, 编程 = 2, \t = 1, 很 = 1, \t = 1, 容易 = 2, \t = 1, 学 = 1
```

### 1.4 原始字符串

```python
r'C:\Users\Admin'     # 反斜杠不当转义符处理
r'C:\test'            # 7个字符(C : \ t e s t)
```

## 二、字符串运算符

| 运算符 | 作用 | 示例 | 结果 |
|--------|------|------|------|
| `+` | 拼接 | `"ab"+"cd"` | `"abcd"` |
| `*` | 重复 | `"ab"*3` | `"ababab"` |
| `in` | 包含判断 | `'he' in 'hello'` | `True` |
| `not in` | 不包含 | `'x' not in 'abc'` | `True` |

### 2.1 运算优先级

```
* (重复) > + (拼接)
```

```python
'a' + 'b' * 2      # b*2='bb', a+'bb'='abb'
('a' + 'b') * 2    # 'ab'*2 = 'abab'
```

### 2.2 铁律

| 规则 | 正确 | 错误 |
|------|------|------|
| 字符串只能 + 字符串 | `"age:" + str(18)` | `"age:" + 18` ❌ |
| 字符串只能 * 整数 | `"hi" * 3` | `"hi" * 3.5` ❌ |
| 乘以0 = 空字符串 | `"abc" * 0` → `""` | — |
| 乘以1 = 本身 | `"abc" * 1` → `"abc"` | — |
| 字符串不可变 | `s = s + "!"` ✅ | `s[0] = 'H'` ❌ |

### 2.3 str() 转换

```python
str(123)         # '123'
str(3.14)        # '3.14'
str(True)        # 'True'
str([1,2,3])     # '[1, 2, 3]'
```

### 2.4 字符串比较

按**Unicode编码**逐字符比较。大写字母 < 小写字母（`'A'=65 < 'a'=97`）。

## 三、切片步长（本章头号重点）

> **🧠 费曼：步长 = 你切面包时每隔几片切一刀。** 步长1=每片都切。步长2=跳着切，第一片、第三片、第五片...步长为负=从右边往左边切。最常用的是`[::-1]`——从最右端开始，步长-1向左走，等于把整条面包翻了个面。步长为正时从左往右（start<end），步长为负时从右往左（start>end），搞反了就是空面包。

### 3.1 完整语法

```
s[start : end : step]
   起始  结束   步长
  (包含)(不包含)
```

**三个参数全部可选**，默认值：
- start 省略 → `0`（正步长）或 `-1`（负步长）
- end 省略 → 末尾（正步长）或开头（负步长）
- step 省略 → `1`

### 3.2 正步长（step > 0）

```
规则：start < end，从左向右取
start ≥ end → 结果为空字符串
```

```python
s = '0123456789'
s[2:8:2]    # '246' (2,4,6)
s[5:1:2]    # ''   (start > end, 空串！)
s[::3]      # '0369'
s[1::2]     # '13579'
```

### 3.3 负步长（step < 0）→ 反向取

```
规则：start > end，从右向左取
start ≤ end → 结果为空字符串
```

```python
s = 'abcdefgh'
s[::-1]     # 'hgfedcba' (反转字符串)
s[::-2]     # 'hfdb'     (从右端隔一个取一个)
s[-2::-2]   # 'geca'     (从倒数第2个向左隔一取)
s[5:0:-2]   # 'fdb'      (从f向左隔一取到索引0前)
s[2:8:-1]   # ''         (start < end, 空串！)
```

### 3.4 反转字符串 = `s[::-1]`

这是全书最重要的切片模式，牢记。

### 3.5 切片不会越界报错

```python
s = 'hello'
s[1:100]    # 'ello' (end自动截断为长度)
s[-100:3]   # 'hel'  (start自动截断为0)
s[::0]      # ❌ ValueError: slice step cannot be zero
```

### 3.6 常见切片模式速查

| 模式 | 含义 | 示例(`'abcdefgh'`) |
|------|------|------|
| `s[::-1]` | 反转 | `'hgfedcba'` |
| `s[::2]` | 隔一字取 | `'aceg'` |
| `s[1::2]` | 从第二字隔一取 | `'bdfh'` |
| `s[::-2]` | 逆向隔一取 | `'hfdb'` |
| `s[:]` | 完整副本 | `'abcdefgh'` |
| `s[1:7:2]` | 指定范围跳步 | `'bdf'` |

## 四、综合实战题

```python
# 取数字
s = '0a1b2c3d4e5f6g'
s[0::2]           # '0123456' (跳步取数字)
s[0:-1:2]         # '0123456'

# 取字母
s = '0a1b2c3d4e5f6g'
s[1::2]           # 'abcdefg'

# 反向取数字
s[-2::-2]         # '6543210'

# 中文切片
s = "一二三四五六七八九十"
s[1:7:2]          # '二四六'
s[::-1]           # '十九八七六五四三二一'

# 字符串运算
'py' + 'thon' * 0    # 'py'     (thon*0='')
('a'+'b') * 3         # 'ababab'
'x'*3 + 'y'*2         # 'xxxyy'
'hello' * 2 + 'world' * 0  # 'hellohello'

# str转换拼接
print("s=" + str(5050))     # s=5050
print(a + " " + str(3.0))   # python 3.0
```

## 五、高频易错速查

| 陷阱 | 正确答案 |
|------|----------|
| `" "`是空字符串？ | ❌ 含空格，长度1。空串是`""`或`''` |
| Python字符串界定符有括号？ | ❌ 只有单/双/三引号 |
| 中文双引号""能界定字符串？ | ❌ 只认英文引号 |
| 三引号只能多行？ | ❌ 单行也能用 |
| `s[1:5:-1]`结果？ | `''` 空串（start<end,负步长） |
| `s[5:1:2]`结果？ | `''` 空串（start>end,正步长） |
| `s[::0]`合法？ | ❌ 步长不能为0 |

| `'abc'*2+'def'` | `'abcabcdef'` |
| 空串*5 | `''` |
| 空串+'test' | `'test'` |

| `s[::-1]`做什么？ | 反转字符串 |
| 如何输出 `s=5050`？ | `print("s="+str(5050))` |

### 答案与解析

| 题号 | 答案 | 解析 |
|------|------|------|
| 1 | **B** | p(1)y(2)\\n(1)t(1)h(1)\\t(1)O(1)N(1) = 8。\\n和\\t各算1个字符，别数成2个。 |
| 2 | **B** | 空串=`""`或`''`。A含空格长度1，C是字符串"0"，D是判断==不是赋值。 |
| 3 | **B** | 字符串\*N = 重复N遍。`"abc"*3`=`"abcabcabc"`。 |
| 4 | **B** | 先乘后加：`'b'*2='bb'`，`'a'+'bb'='abb'`。 |
| 5 | **A** | a(0)b(1)c(2)d(3)e(4)f(5)g(6)h(7)。`s[1:7:2]`=b(1),d(3),f(5)=`'bdf'`。 |
| 6 | **A** | 负步长从右往左：h(7)→f(5)→d(3)→b(1)=`'hfdb'`。 |
| 7 | **C** | start=1 < end=5 但步长为负→矛盾→空串。正步长要start<end，负步长要start>end。 |
| 8 | **C** | `s[::-1]`是反转字符串的标准写法。B：步长不能为0。D：字符串没有reverse()方法。 |
| 9 | **B** | `\"`转义为双引号字符，输出`He said "OK"`。 |
| 10 | **C** | 字符串+整数 → TypeError。必须用`"hello"+str(5)`。 |
| 11 | **B** | 三引号内单双引号都不用转义。A和C和D都有未转义引号问题。 |
| 12 | **C** | `('a'+'b')='ab'`，`'ab'*3='ababab'`。 |
| 13 | **B** | `str(True)`→`'True'`，`int(True)`才是`1`。 |
| 14 | **A** | 1(0)2(1)3(2)4(3)5(4)。`s[-2]`=4(3)，`s[-2::-1]`=4(3),3(2),2(1),1(0)=`'4321'`。 |
| 15 | **B** | `'x'*3='xxx'`，`'y'*2='yy'`，`'xxx'+'yy'='xxxyy'`。运算符优先级：`*`高于`+`。 |
