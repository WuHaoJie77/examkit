# Python题库浓缩版 使用说明

## 这是什么

把超星/学习通Python期末题库 **13章1300+道题** 压成13张速记卡。去掉重复题，提取核心考点，每章配15道自测。
适合：考前突击、刷题前过一遍、忘光了快速捡起来。

## 每章结构

每章固定七块：

| 模块 | 内容 |
|------|------|
| 🧠 费曼例子 | 每个知识点前有一个生活类比（储物柜=变量、切面包=切片、购物车=列表...），3秒建立直觉 |
| 知识浓缩 | 考点按主题分类，表格化，公式化 |
| 高频坑速查 | 最容易选错的判断题/选择题，一行一坑 |
| 经典模板 | 常见代码填空的标准答案，背诵即用 |
| 自测15题 | 覆盖全章的检测题 |
| 答案与解析 | 每题为什么对、为什么错 |
| 评分线 | 错几个该回去重看，分段指导 |

## 用什么打开

**推荐：VS Code**（学Python大概率已装）
打开文件 → `Ctrl+Shift+V` 预览，表格和代码块渲染完整。

**浏览器**
装个 Markdown Viewer 插件（Chrome/Edge应用商店搜，免费），拖文件进去。

**Typora / Obsidian**
写笔记顺便看，渲染效果好。

## 怎么用（每章30分钟）

1. **先看费曼例子**（1分钟）— 用生活场景建立画面感
2. **通读知识浓缩**（10分钟）— 表格和规则扫一遍，别做题
3. **扫高频坑速查**（3分钟）— 考试翻车高发区，了然于胸
4. **做自测15题**（8分钟）— 不看答案，独立完成
5. **对答案看解析**（5分钟）— 错题回到对应模块补
6. **开刷原题库**（3分钟）— 正确率基本90%+

13章 × 30分钟 ≈ **6.5小时全覆盖**。

## 适合人群

- 超星/学习通Python期末考试突击

- 刷题前先过考点，避免盲目刷题
- 考前最后一天速通全书

## 注意事项

- 这是**浓缩版**，不是题库全集。目的是帮你拎出考点框架，不保证覆盖100%原题。
- 浓缩版答对 → 原题大概率也对。浓缩版错了 → 原题必错，赶紧补。
- 别跳过费曼例子——很多人卡在抽象概念上，3秒类比直接打通。
- 别跳过自测。不测不知道自己哪里没记住。
- 每章的评分线是硬指标，达标再进下一章。
