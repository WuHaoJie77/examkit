## 一、计算机网络概述

> 🍳 **费曼：计算机网络像「快递网络」——你在北京发包裹(数据)，经过分拣中心(路由器)、走高速(光纤)、到广州分拣中心、最后由快递员送到收件人手里。通信子网是物流系统(送包裹)，资源子网是你的包裹里的东西(数据和服务)。**

### 1.1 定义与组成

```
计算机网络 = 独立计算机 + 通信设施 + 网络软件 + 协议 → 实现资源共享

宏观：计算机系统 + 通信链路 + 网络节点
逻辑：资源子网 + 通信子网
```

| 部分 | 组成 | 功能 |
|------|------|------|
| **资源子网** | 主机系统、终端控制器、终端 | 提供资源共享的硬件/软件/数据 + 访问网络和处理数据的能力 |
| **通信子网** | 网络节点、通信链路、信号变换器 | **完成数据的传输、交换和控制** + 提供网络通信功能 |

### 1.2 四大功能

| 功能 | 说明 |
|------|------|
| **信息交换** | 最基本功能：节点间通信（邮件/新闻/购物/远程教育） |
| **资源共享** | 硬件、软件、数据共享 |
| **提高可靠性** | 冗余备份，单点故障不影响整体 |
| **分布式处理** | 多机协同完成大型任务 |

### 1.3 按覆盖范围分类

| 类型 | 范围 | 例子 |
|------|------|------|
| **局域网(LAN)** | 100m~几十km | 校园网、公司网 |
| **城域网(MAN)** | 几km~150km | 城市宽带网 |
| **广域网(WAN)** | 100km~1000km+ | **Internet** |

### 1.4 按用途分类

校园网、企业网、公用网、专用网、内联网(Intranet)、外联网(Extranet)

> ⚠️ 内联网/外联网连接Internet时必须经过**防火墙和访问认证**

## 二、以太网

> 🍳 **费曼：以太网像「对讲机群聊」——所有人共用一个频道，谁想说话先听一下有没有人在说(载波监听)，如果恰好两个人同时开口就撞车了(冲突检测)，两人都闭嘴随机等一会儿再说。**

| 方面 | 内容 |
|------|------|
| 地位 | 应用**最广泛**的局域网技术 |
| 标准 | IEEE 802.3 |
| 核心协议 | **CSMA/CD**（载波监听多路访问/冲突检测） |
| 本质 | 基带总线局域网 |

| 类型 | 速率 | 标准 |
|------|------|------|
| 快速以太网 | 100Mbps | 100Base-T |
| 千兆以太网 | 1Gbps | IEEE 802.3z/ab |
| 万兆以太网 | 10Gbps | IEEE 802.3ae |
| 更高速 | 40-100Gbps | IEEE 802.3ba |

> ⚠️ **以太网是局域网，不是广域网！**

## 三、网络体系结构

> 🍳 **费曼：OSI像「七层豪华蛋糕」——每层只管自己的事，上层调用下层服务。TCP/IP像「四层快手蛋糕」——把OSI上面几层合并简化，够用就好。Internet用的是TCP/IP，OSI是理论模型没真正流行。**

### 3.1 体系结构定义

```
A = (S, E, L, P)
A=体系结构  S=系统  E=实体(进程)  L=层(功能群)  P=协议(通信规则)
```

### 3.2 OSI七层模型（理论）

| 层 | 名称 | 功能 |
|----|------|------|
| 7 | 应用层 | 用户应用服务 |
| 6 | 表示层 | 数据格式转换 |
| 5 | 会话层 | 建立/管理会话 |
| 4 | 传输层 | **端到端**可靠传输 |
| 3 | 网络层 | 路由选择 |
| 2 | 数据链路层 | 帧传输 |
| 1 | 物理层 | 比特流传输 |

### 3.3 TCP/IP四层模型（实际）

| 层 | 对应OSI | 核心协议 | 功能 |
|----|---------|----------|------|
| **应用层** | 5-7层 | HTTP/FTP/SMTP/DNS | 用户应用服务，**C/S模型实现层** |
| **传输层** | 4层 | **TCP**(面向连接)、**UDP**(无连接) | 端到端通信 |
| **互联网层** | 3层 | **IP**（核心） | 路由、数据报传输 |
| **网络接口层** | 1-2层 | — | 接收/发送物理帧 |

### 3.4 OSI vs TCP/IP对比

| | 相同点 | 不同点 |
|------|--------|--------|
| OSI(7层) | 都是层次结构、底层面向通信子网、顶层为应用层 | 层数多、无会话/表示层对应、偏理论 |
| TCP/IP(4层) | 同上 | 层数少、注重实用、Internet核心 |

> ⚠️ **Internet遵循的是TCP/IP模型，不是OSI！**
> ⚠️ **TCP/IP网络接口层对应OSI物理层+数据链路层，不是OSI网络层！**

## 四、TCP vs UDP

> 🍳 **费曼：TCP像「挂号信」——先确认对方能收到(三次握手)，寄出后等回执(确认)，丢了重寄(重传)。UDP像「扔纸飞机」——写好就扔，不管对方收到没，快但不可靠。**

| | TCP | UDP |
|------|-----|-----|
| 连接 | **面向连接**（三次握手） | **无连接** |
| 可靠性 | **可靠**（确认、重传、流量控制） | 不可靠（无确认，易丢包） |
| 开销 | 大（维护连接状态） | **小** |
| 速度 | 慢 | **快** |
| 适用 | 文件传输(FTP)、邮件(SMTP)、网页(HTTP) | 视频通话、直播、DNS |

> 🔑 **TCP和UDP都是TCP/IP模型传输层协议**

## 五、网络组成与互连设备

### 5.1 五大基本组成

| 组件 | 说明 |
|------|------|
| **服务器** | 提供服务（文件/打印/Web） |
| **工作站** | 使用服务的节点 |
| **网卡(NIC)** | 连接网络，每网卡有**唯一MAC地址** |
| **传输介质** | 双绞线、同轴电缆、光纤 |
| **共享资源与外设** | 存储设备、打印机、绘图仪等 |

### 5.2 网络互连设备

| 设备 | 功能 | 层级 |
|------|------|------|
| **中继器** | 放大信号，连接总线 | 物理层 |
| **集线器** | 连接多设备，构成**星形结构** | 物理层 |
| **网桥** | 检查目标地址，转发跨总线数据 | 数据链路层 |
| **交换机** | 多端口网桥，减少传输负荷 | 数据链路层 |
| **路由器** | 连接不同网络，转换网络特性 | 网络层 |
| **三层交换机** | 基于硬件的路由功能（交换机+路由器整合） | 网络层 |

### 5.3 网络拓扑

| 信道类型 | 拓扑 | 特点 |
|----------|------|------|
| **点-点线路** | 星形 | 中心节点控制，单机故障不影响其他 |
| | 环形 | 数据单向传输，**1台故障导致环中断** |
| | 树形 | 层次连接 |
| | 网状 | 可靠性高，需路由算法 |
| **广播信道** | 总线型 | 共享信道，易冲突 |

## 六、Internet协议与应用

### 6.1 核心协议

| 协议 | 全称 | 功能 | 层级 |
|------|------|------|------|
| **IP** | 网际协议 | 路由选择、数据报传输 | 互联网层 |
| **TCP** | 传输控制协议 | 面向连接可靠传输 | 传输层 |
| **UDP** | 用户数据报协议 | 无连接快速传输 | 传输层 |
| **HTTP** | 超文本传输协议 | Web浏览 | 应用层 |
| **FTP** | 文件传输协议 | 双向文件传输（数据+控制双连接） | 应用层 |
| **SMTP** | 简单邮件传输协议 | 发送邮件 | 应用层 |
| **POP3** | 邮局协议v3 | 下载邮件到本地 | 应用层 |

### 6.2 三种地址

| 地址类型 | 定义 | 例子 | 特点 |
|----------|------|------|------|
| **用户地址** | 面向用户的易记地址 | `www.baidu.com`、`xxx@163.com` | 依赖网络层地址存在 |
| **网络层地址(IP)** | 网络中计算机的逻辑地址 | `220.181.37.55`（IPv4, 32位） | 唯一标识主机，用于路由 |
| **物理地址(MAC)** | 网卡出厂固化的硬件地址 | `00-1A-2B-3C-4D-5E` | **不可修改**，同一子网内帧传输 |

> 🔑 关系：一个IP→多个用户地址，一个用户地址→一个IP。一个主机多网卡→多MAC。

### 6.3 三种连入Internet方式

1. 连到以Internet为主机的局域网（校园网/企业网）
2. 通过宽带直接接入Internet主机
3. 通过宽带接入Internet服务的联机服务系统（ISP）

### 6.4 Internet三大基本服务

| 服务 | 协议 | 说明 |
|------|------|------|
| **电子邮件(E-mail)** | SMTP/POP3 | 存储转发，支持多媒体 |
| **远程登录(Telnet)** | Telnet | 模拟远程主机终端 |
| **文件传输(FTP)** | FTP | 双向传输，支持匿名登录 |

### 6.5 C/S模型

客户机(Client)请求→服务器(Server)处理→返回结果。**在TCP/IP的应用层实现**（HTTP/FTP/SMTP都基于此模型）。

## 七、移动通信与无线网络

### 7.1 有线网 vs 无线网

| | 有线网 | 无线网 |
|------|--------|--------|
| 优点 | 速度快、稳定、**安全** | **灵活**、易安装、易扩展 |
| 缺点 | 布线复杂、灵活性差 | 速度较慢、易干扰、**安全性差** |

### 7.2 移动通信发展历程

| 代 | 年代 | 技术 | 特点 |
|----|------|------|------|
| **1G** | 1975-1985 | 模拟调制 | 仅话音，已淘汰 |
| **2G** | 1985-2005 | 数字调制(GSM/CDMA) | 话音+短信，衍生GPRS/EDGE |
| **3G** | 2005-2012 | 宽带化(WCDMA等) | 移动多媒体，催生iPhone |
| **4G** | 2012-2019 | LTE | 高速传输、物联网、IPv6 |
| **5G** | 2019至今 | 增强移动宽带 | 低时延、广连接、VR/AR/工业互联网 |
| **6G** | 未来 | — | Tbit/s级、空天地一体化、AI融合 |

### 7.3 蜂窝移动通信原理

1. **蜂窝小区划分**：地理区域分正六边形小区（理想），实际受地形影响形状不同
2. **频率复用**：区群内不同频率，区群间复用
3. **自动越区切换**：移动台跨小区→自动切换基站
4. **移动IP**：漫游保留原IP，通过代理转发
5. **非对称传输**：下行速率(下载) > 上行速率(上传)

### 大题参考答案

**16. OSI vs TCP/IP**

| | OSI(7层) | TCP/IP(4层) |
|------|----------|-------------|
| 层次 | 物理→数据链路→网络→传输→会话→表示→应用 | 网络接口→互联网→传输→应用 |
| 特点 | 理论模型，层次清晰 | 实用模型，Internet核心 |
| 相同点 | 都是层次结构、底层面向通信子网、顶层为应用层 | |

Internet使用**TCP/IP模型**。

**17. TCP vs UDP**

| | TCP | UDP |
|------|-----|-----|
| 连接 | 面向连接（三次握手） | 无连接 |
| 可靠性 | 可靠（确认/重传） | 不可靠 |
| 开销 | 大 | 小 |
| 应用 | FTP文件传输、HTTP网页 | 视频通话、DNS域名解析 |

相同点：都是TCP/IP传输层协议，都基于IP提供端到端通信。

**18. 三种地址**

| 地址 | 定义 | 特点 |
|------|------|------|
| 用户地址 | 易记地址(域名/邮箱) | 依赖IP存在 |
| IP地址 | 网络层逻辑地址 | 用于路由，可配置 |
| MAC地址 | 网卡硬件地址 | 出厂固化，不可修改 |

**不能一对一**：一个IP(邮件服务器)可对应多个用户地址(多用户邮箱)，一个主机多网卡对应多个MAC地址。

**19. 网络组成与设备**

五部分：服务器+工作站+网卡+传输介质+共享资源

| 设备 | 功能 | 层 |
|------|------|-----|
| 中继器 | 放大信号 | 物理层 |
| 集线器 | 连接多设备，星形结构 | 物理层 |
| 网桥 | 检查地址转发 | 数据链路层 |
| 交换机 | 多端口网桥 | 数据链路层 |
| 路由器 | 连接不同网络 | 网络层 |

**20. 移动通信发展**

1G(模拟话音)→2G(数字+短信)→3G(移动多媒体)→4G(LTE高速+物联网)→5G(低时延+广连接+VR/AR)

蜂窝原理：①正六边形小区划分 ②频率复用(区群内不同频率) ③自动越区切换 ④移动IP(漫游保留原IP) ⑤非对称传输(下行>上行)
