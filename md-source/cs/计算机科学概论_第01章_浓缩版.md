## 一、数制基础

> 🍳 **费曼：数制就像「打包规则」——十进制每10个打一包，二进制每2个打一包。位置化数制关心东西放在第几个箱子（位置决定价值），非位置化数制只看东西本身值多少（罗马数字I放哪都是1）。**

### 1.1 两大类数制

| 类型 | 规则 | 例子 | 计算机用？ |
|------|------|------|-----------|
| **位置化** | 数码值 = 数码 × 底^位置权 | 十进制(底10)、二进制(底2)、八进制(底8)、十六进制(底16)、六十进制(底60) | ✅ 核心 |
| **非位置化** | 数码值固定，与位置无关 | 罗马数字(I/V/X/L/C/D/M) | ❌ |

### 1.2 常见数字系统速查

| 系统 | 底 | 数码 | 用途 | 后缀 |
|------|-----|------|------|------|
| 二进制 | 2 | 0,1 | 计算机核心 | B |
| 八进制 | 8 | 0-7 | 二进制缩写 | **O** (或Q) |
| 十进制 | 10 | 0-9 | 日常 | D |
| 十六进制 | 16 | 0-9,A-F | 二进制缩写（最优） | H |
| 六十进制 | 60 | — | 时间/角度 | — |

> 🌍 **巴比伦文明发展了首个位置化数字系统：六十进制**

## 二、进制转换

> 🍳 **费曼：整数转换像「分糖果」——不断除以目标进制，把每次剩下的糖（余数）记下来倒着读。小数转换像「量布料」——不断乘以目标进制，每次裁下来的整块（整数部分）顺着读。**

### 2.1 转换方法

| 转换方向 | 整数部分 | 小数部分 |
|----------|----------|----------|
| 十进制→R进制 | **连除法**：不断÷R，余数**逆序**排列 | **连乘法**：不断×R，整数**顺序**排列 |
| R进制→十进制 | Σ(数码×R^位置权) | 同上（负指数） |
| 二进制→八进制 | 从右往左**3位一组** | 从左往右3位一组 |
| 二进制→十六进制 | 从右往左**4位一组** | 从左往右4位一组 |
| 八/十六→二进制 | 1位拆3位 / 1位拆4位 | 同上 |

### 2.2 速算技巧

- 二进制末尾加1个0 → ×2；加2个0 → **×4**
- 二进制末尾去掉1个0 → ÷2
- 100₁₀ = 1100100₂ = 144₈ = 64₁₆

### 2.3 各进制优缺点

| 进制 | 优点 | 缺点 |
|------|------|------|
| 二进制 | 仅0/1→硬件易实现(开关)、运算规则简单(加法仅3种) | 数串太长，不易读写 |
| 八进制 | 1位=3位二进制，缩短串长 | 数码范围小(0-7)，缩写效果不如十六进制 |
| 十六进制 | 1位=4位二进制，**缩写效果最优** | 需记A-F(10-15)，数码多 |

> 🤔 **为什么计算机用二进制？三合一：①降低硬件成本 ②两状态系统稳定 ③运算法则简单**

## 三、整数的表示：原码·反码·补码

> 🍳 **费曼：原码像「贴标签」——正数标+，负数标-，但加减时标签会捣乱。反码像「把负数的数字全部翻面」，但翻出两个0（+0和-0）。补码像「翻面后再+1」——完美消除双0，符号位能参与运算，减法变加法，电路最简洁。**

### 3.1 三码对比（以8位为例）

| | 正数 | 负数 | +0 / -0 | 特点 |
|------|------|------|---------|------|
| **原码** | 符号位0+数值位 | 符号位**1**+绝对值二进制 | 有+0和-0 | 乘除正确，**加减错误** |
| **反码** | 同原码 | 符号位1+数值位**全部取反** | **有两个0** (00000000和11111111) | 解决部分加减问题 |
| **补码** | 同原码 | **反码+1** | **只有一个0** | ✅ 计算机实际使用 |

### 3.2 补码核心优势

1. **符号位参与运算**，简化规则
2. **减法转加法**：a-b = a+(-b)的补码，简化运算器电路
3. 无"-0"，8位表示范围：-128 ~ 127

### 3.3 溢出

- **原因**：存储位数固定，可表示范围有限
- 8位补码范围 -128~127，超出则溢出，高位舍弃，结果错误
- 本质：**有限存储 vs 无限数值**的矛盾

### 3.4 位与字长

| 概念 | 说明 |
|------|------|
| **位(bit)** | 数据最小单位，也是存储器最小单位 |
| **字长** | **与微处理器型号有关**（8位CPU→8位，32位→32位），非固定值 |
| 32位可表示 | 2³² 个不同ID |

## 四、实数的表示

> 🍳 **费曼：浮点数像「科学计数法」——不说1230000，说1.23×10⁶。规范化的意思就是小数点左边只留唯一一个非零数字。**

| 概念 | 说明 |
|------|------|
| 浮点数组成 | **阶码**(指数) + **尾数**(有效数字) |
| **规范化** | 小数点左边唯一非零数码（十进制的科学计数法、二进制的浮点表示都遵守） |

## 五、字符编码

> 🍳 **费曼：ASCII像「英文身份证」——7位编号够128个字符。Unicode像「全球护照」——16/32位编号覆盖所有语言。汉字编码是「三层翻译」：输入码(拼音/五笔)→机内码(计算机内部存储，双字节最高位置1)→国标码(交换用)。**

### 5.1 ASCII vs Unicode

| | ASCII | Unicode |
|------|-------|---------|
| 位数 | **7位**基础（+1校验=8位） | 16位或32位 |
| 字符数 | 128个 | 65536+，覆盖全球语言 |
| 范围 | 英文（数字、字母、标点、控制符） | 全球所有文字符号 |
| 局限 | **无法表示非英文字符**，多语言编码冲突 | — |
| 为什么要推行Unicode | — | 统一编码标准，跨语言跨平台交换，解决ASCII局限 |

### 5.2 ASCII码记忆点

- 'N' = 4EH → 01001110B
- 'J' = 4AH → 01001010B
- 同字母大小写差32：'A'=65, 'a'=97
- 排序：数字<大写字母<小写字母

### 5.3 汉字编码三层体系

| 编码 | 说明 | 关键特征 |
|------|------|----------|
| **国标码 (GB2312-80)** | 信息交换基础编码 | 收录6763汉字+682非汉字，94区×94位，又称**区位码** |
| **机内码** | 计算机内部存储/处理 | **双字节**，每个字节**最高位置1**（区分ASCII） |
| **输入码** | 键盘输入用 | 4类（见下） |

### 5.4 汉字输入码四类

| 类型 | 代表 | 优点 | 缺点 |
|------|------|------|------|
| 数字编码 | **区位码**、电报码 | 无重码 | 难记 |
| 字音编码 | **拼音码**、智能ABC | 易学好记 | 重码多 |
| 字形编码 | **五笔字型**、表形码 | 重码少 | 难学 |
| 音形编码 | 自然码 | 平衡重码与难度 | — |

> 🔑 **汉字从键盘到存储的流程：输入码 → 机内码（存储）**

## 六、图像与多媒体

> 🍳 **费曼：位图像「马赛克拼图」——记录每个小方块的颜色，图越大方块越多文件越大。矢量图像「菜谱」——只记「画一个半径5cm的圆」，不管画多大文件一样小。压缩就是问「能不能少记几个方块还不被看出来？」**

### 6.1 位图 vs 矢量图

| | 位图 | 矢量图 |
|------|------|--------|
| 存储方式 | 像素矩阵（每个点的颜色） | 数学公式（直线端点、圆半径） |
| 缩放 | 放大出现锯齿 | 任意缩放不失真 |
| 占用空间 | **大**（取决于像素数和位深度） | **小**（与图像尺寸无关） |
| 常见格式 | BMP、JPEG、GIF、TIFF | SVG、AI、EPS |

### 6.2 图像格式对比

| 格式 | 压缩 | 占用空间 | 适用 |
|------|------|----------|------|
| **BMP** | ❌ 无压缩 | **最大** | 原始图像 |
| JPEG | 有损/无损，压缩比10:1~40:1 | 小 | 照片 |
| GIF | 无损(LZW) | 较小 | 简单图形/动画 |

> 💡 **空间最小：高压缩比JPEG 或 矢量图**

### 6.3 显存计算

```
显存容量(字节) = 像素数 × 位深度 ÷ 8
  
例：1024×768 真彩色(24位) = 1024×768×24÷8 = 1024×768×3 字节
```

### 6.4 位深度与灰度

| 位深度 | 灰度级 | 规律 |
|--------|--------|------|
| 2位 | 4级 | 位模式越大→明暗变化越**细致** |
| 8位 | 256级 | 2^位深度 = 灰度级数 |

### 6.5 音频

| 概念 | 说明 |
|------|------|
| MP3 | MPEG Audio Layer-3，最普及的音频压缩格式 |
| 采样频率 | 常见：**11kHz、22kHz、44kHz**（55Hz❌） |
| 文件大小公式 | (采样频率 × 量化位数 × 声道 × 时间) / 8 |
| 采样频率与文件大小 | **成正比**（其他条件相同时） |

### 6.6 多媒体基础

| 概念 | 说明 |
|------|------|
| 媒体五分类 | 感觉媒体、表示媒体、表现媒体、存储媒体、传输媒体 |
| 多媒体信息 | 音频/视频 + 影像/动画 + 文字/图形（光盘❌→存储介质非信息） |
| 多媒体系统 | 本质是**交互式系统**（人机交互） |
| 条形码 | 属于**机读数据**（非人读/计算/输出数据） |

## 八、计算应用题模板

### 8.1 二进制位数计算

```
n位二进制可表示 2ⁿ 个唯一ID
问题：N个员工需要多少位？→ 找最小n使 2ⁿ ≥ N

例：500员工 → 2⁸=256<500, 2⁹=512≥500 → 9位
    +200=700 → 2⁹=512<700, 2¹⁰=1024≥700 → 需调整到10位
```

### 8.2 组合计数

```
总数 = 每位选择数相乘
例：车牌 = 1字母(26) + 5位数字(10) → 26×10⁵ = 260万
    首位非0 → 26×9×10⁴ = 234万
```

## 九、高频易错速查

| 陷阱 | 正确答案 |
|------|----------|
| 计算机内部数据用八/十/十六进制表示？ | ❌ 计算机内部只用**二进制**，其他进制是给人看的 |
| 计算机硬件能直接识别高级语言？ | ❌ 只能直接识别**机器语言**（二进制指令） |
| 浮点数由整数+小数组成？ | ❌ 由**阶码+尾数**组成 |
| 字长固定为16或32位？ | ❌ **与微处理器型号有关**，不同CPU字长不同 |
| 1M = 1024K？ | ❌ 1M准确含义是 **1024×1024** 字节 |
| 汉字在计算机内占1个字节？ | ❌ GB2312-80汉字机内码占**2个字节** |
| ASCII码用8位表示？ | ❌ 标准ASCII用**7位**基础编码 |
| 八进制后缀是H？ | ❌ 八进制O/Q，十六进制H，二进制B |
| 十六进制数码包含G？ | ❌ 十六进制数码：0-9,A-F，**G非法** |
| BMP占用空间最小？ | ❌ BMP无压缩，占用空间**最大** |
| 条形码属于人读数据？ | ❌ 条形码是**机读数据** |
| 光盘/声卡是多媒体信息？ | ❌ 是存储介质/硬件，**非信息** |
| 采样频率55Hz常见？ | ❌ 常见：**11k/22k/44kHz** |
| 位模式越短灰度越细致？ | ❌ 位模式越**长**，灰度越丰富 |
| 二进制末尾加两个0→×2？ | ❌ 加1个0×2，加2个0×**4** |
| 原码和补码都能正确做加减？ | ❌ 原码**加减错误**，计算机用**补码** |
| 规范化的浮点数小数点左边可以有多个非零位？ | ❌ 规范化要求小数点左边**唯一非零数码** |

### 大题参考答案

**16. 原码·反码·补码**

| 编码 | 正数 | 负数 | 问题 |
|------|------|------|------|
| 原码 | 符号位0+数值位 | 符号位1+绝对值二进制 | 加减计算错误（1-1=0算出-2） |
| 反码 | 同原码 | 符号位1+数值位全部取反 | 存在+0和-0两个零 |
| 补码 | 同原码 | 反码+1 | ✅ 唯一0，符号位参与运算 |

计算机采用补码的原因：①符号位可直接参与运算 ②减法转加法（a-b = a+补码(-b)），简化运算器电路设计 ③消除±0歧义。

**17. 十进制123的转换**

```
123₁₀ 转二进制（连除法）：
123÷2=61余1 → 61÷2=30余1 → 30÷2=15余0 → 15÷2=7余1
→ 7÷2=3余1 → 3÷2=1余1 → 1÷2=0余1
逆序：1111011₂

转八进制：二进制从右往左3位一组 → 001 111 011 → 173₈
转十六进制：二进制从右往左4位一组 → 0111 1011 → 7B₁₆
```

快捷方法：二进制→八进制：3位拆1位；二进制→十六进制：4位拆1位。反之亦然。

**18. 汉字编码三层体系**

键盘输入 → **输入码**（拼音/五笔/区位，解决「如何输入」）→ 转换为 **机内码**（双字节每字节最高位置1，解决「如何存储处理」）→ 需要交换时用 **国标码**（GB2312-80，94区×94位，解决「系统间交换」）

| 编码 | 作用 | 特征 |
|------|------|------|
| 输入码 | 键盘录入 | 拼音/五笔/区位/自然码四类 |
| 机内码 | 内部存储处理 | 双字节，每字节最高位置1 |
| 国标码 | 信息交换 | 6763汉字+682非汉字，又称区位码 |

**19. 位图 vs 矢量图**

| | 位图 | 矢量图 |
|------|------|--------|
| 存储 | 像素点阵（逐点记录颜色） | 数学公式（直线、曲线、填充） |
| 优点 | 色彩丰富，适合照片 | 任意缩放不失真，文件小 |
| 缺点 | 放大有锯齿，文件大 | 不适合复杂照片 |
| 适用 | 照片、扫描件 | 图标、logo、工程图 |
| 1024×768真彩色显存 | 1024×768×3 = **2,359,296字节 ≈ 2.25MB** | 不适用（矢量图不按像素存储） |

**20. 二进制ID位数计算**

① 500员工：n位二进制可表示2ⁿ个ID。2⁸=256<500，2⁹=512≥500 → **最少9位**

② +200=700员工：2⁹=512<700，2¹⁰=1024≥700 → **需调整到10位**

判断依据：寻找最小的n使2ⁿ≥员工总数。位数不够会导致ID冲突，必须调整。
