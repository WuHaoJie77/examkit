## 一、硬件系统总览

> 🍳 **费曼：CPU像「厨房的厨师」——运算器负责切菜炒菜(计算)，控制器负责指挥工序(协调)。存储器像「冰箱+台面」——主存是台面上正在用的食材(RAM易失，断电就没了)，外存是冰箱里囤的货(永久保存)。I/O设备像「买菜和上菜」——输入是把菜买进厨房，输出是把菜端上桌。**

### 1.1 五大部件

```
计算机硬件系统 = 处理器(CPU) + 存储器 + 总线 + 输入设备 + 输出设备
```

### 1.2 CPU组成

| 部件 | 功能 | 子部件 |
|------|------|--------|
| **运算器(ALU)** | 算术/逻辑运算 | 加法器、移位器、多路选择器、通用寄存器组、控制电路 |
| **控制器** | 取指、译码、控制执行 | CPU寄存器组、操作控制部件、时序部件 |
| **寄存器组** | CPU内部高速暂存 | 为运算器和控制器服务 |

> ⚠️ **CPU = 运算器 + 控制器（不含存储器！存储器是独立部件）**

### 1.3 ALU关键点

- ✅ 能完成算术运算（加减等）
- ✅ 能完成逻辑运算（与或非异或）
- ✅ 是组合逻辑电路（输出仅取决于当前输入）
- ❌ ALU运算**需要**时钟信号来同步（虽然ALU本身是组合逻辑，但在CPU中需要时钟）

## 二、存储器体系：三级存储金字塔

> 🍳 **费曼：三级存储像「办公桌系统」——Cache是桌面随手拿的文件(超快但小)，主存是抽屉里的常用文件(中等速度)，外存是档案柜的归档文件(慢但大)。CPU先摸桌面→没有就翻抽屉→再没有才去档案柜。**

### 2.1 三级存储

| 层级 | 速度 | 容量 | 成本 | 与CPU距离 |
|------|------|------|------|-----------|
| **Cache（SRAM）** | 最快（1-10ns） | 最小（几MB） | 最高 | 最近 |
| **主存（RAM+ROM）** | 中等（10-100ns） | 中等（8-64GB） | 中 | 近 |
| **外存（HDD/SSD）** | 最慢（ms级） | 最大（TB级） | 最低 | 最远 |

### 2.2 多级存储优势

- **平衡速度**：Cache匹配CPU→主存衔接→外存弥补
- **平衡容量**：外存大容量弥补主存不足
- **平衡成本**：高速小容量+低速大容量→综合性价比最优
- **访问频度**：越上层访问越频繁（高频数据在上，低频在下）

### 2.3 内存 vs 外存

| | 内存（主存） | 外存（辅存） |
|------|-------------|-------------|
| 速度 | 快（DRAM 10-100ns） | 慢（HDD 5-10ms） |
| 易失性 | RAM断电丢失 | **断电保留** |
| 容量 | 小（8-64GB） | 大（1-20TB） |
| 成本 | 高 | 低 |
| 用途 | 存放当前运行程序 | 长期存储/后备仓库 |
| 归属 | 主机组成部分 | **外部设备（外设）** |

> ⚠️ **外存属于外部设备！CPU不能直接访问外存，必须通过内存中转**

## 三、RAM 详解

> 🍳 **费曼：SRAM像「白板」——写上去就一直显示，不用管。DRAM像「沙画」——画完沙子慢慢流掉，必须每隔一会儿重新描一遍(刷新)。所以SRAM快但贵(做Cache)，DRAM便宜但得刷新(做主存)。**

### 3.1 SRAM vs DRAM

| | SRAM（静态RAM） | DRAM（动态RAM） |
|------|------|------|
| 存储原理 | **双稳态触发器** | MOS管栅极**电容** |
| 刷新 | ❌ 无需刷新 | ✅ 需定期刷新（~64ms） |
| 速度 | 快（1-10ns） | 慢（10-100ns） |
| 集成度 | **低**（晶体管多） | **高**（一个电容+一个晶体管） |
| 成本 | 高 | 低 |
| 用途 | **CPU Cache**（L1/L2/L3） | **主存（内存条）** |

### 3.2 关键辨析

- SRAM和DRAM都属**易失性**存储器（断电丢数据）✅
- "静态RAM信息不易失" ❌ —— 静态只表示无需刷新，断电照样丢
- 计算机主存常用DRAM（集成度高、成本低），不是SRAM
- 提高主存性能的技术：**多体交叉存储**、**Cache**、**DDR内存技术**（DDR4/DDR5双倍数据速率）

## 四、ROM 家族

> 🍳 **费曼：ROM家三兄弟——PROM像「一次性刻字」，刻完改不了；EPROM像「铅笔字」，用紫外线(橡皮)全擦掉重写；EEPROM像「白板笔」，可以局部擦了改，最灵活。**

| 类型 | 全称 | 编程 | 擦除方式 | 应用 |
|------|------|------|----------|------|
| **PROM** | 可编程ROM | 一次性编程 | ❌ 不可擦除 | 老式家电固件 |
| **EPROM** | 可擦除可编程ROM | 可多次编程 | 紫外线照射**整体擦除** | 早期主板BIOS |
| **EEPROM** | 电可擦除可编程ROM | 可多次编程 | **电擦除，可局部改写** | 主板CMOS、U盘、SD卡 |

> 🔑 **ROM共性：非易失性（断电保留数据），用于存储固定程序（如BIOS）**

## 五、辅助存储器（外存）

| 类型 | 原理 | 代表 | 特点 |
|------|------|------|------|
| **磁存储** | 磁性材料记录 | **HDD**（机械硬盘）、磁带 | 大容量、低成本、有机械部件 |
| **光存储** | 激光读写 | CD-ROM、DVD-ROM、蓝光 | 便携、只读为主 |
| **电存储** | 半导体闪存 | **SSD**、U盘、SD卡 | 高速、无机械、低功耗 |

### 闪存替代HDD的原因

- ❌ 无机械部件 → 抗震强、寿命长
- ⚡ 读写快（SSD 3000MB/s vs HDD 200MB/s）
- 🔋 低功耗（适合笔记本/移动端）
- 📏 体积小（M.2接口超薄）

> ⚠️ **容量大≠速度慢**（SSD 4TB照样比小容量HDD快得多）

## 六、Cache与摩尔定律

### 6.1 Cache（高速缓冲存储器）

| 方面 | 内容 |
|------|------|
| 位置 | CPU与主存之间 |
| 原理 | **程序访问局部性**（CPU一段时间内只访问主存局部区域） |
| 工作流程 | CPU先查Cache → 命中直接读 → 未命中从主存取并写入Cache |
| 作用 | 解决CPU与主存**速度不匹配**，减少CPU等待 |
| 速度 | 接近CPU速度，远快于主存（不是"远慢于CPU"！） |

### 6.2 摩尔定律（戈登·摩尔，1965）

| 要素 | 内容 |
|------|------|
| 周期 | 18~24个月 |
| 晶体管 | 芯片上晶体管数量**翻一番** |
| 性能 | 处理器性能**提高一倍** |
| 成本 | 单位性能成本**同比下降一半** |
| 意义 | 硬件发展预测依据、软硬件协同规划、芯片制程升级节奏 |

## 七、I/O设备与接口

### 7.1 I/O设备三大类

| 类别 | 说明 | 例子 |
|------|------|------|
| **机-机通信** | 计算机与设备/系统通信 | 网卡、调制解调器、数模转换器 |
| **存储类** | 辅助存储器（外存） | HDD、SSD、光盘 |
| **人机交互** | 人与计算机交换信息 | 输入：键盘、鼠标、**扫描仪**；输出：显示器、打印机、音箱 |

> ⚠️ **扫描仪 = 输入设备**（把图像转为数字信号进入计算机）

### 7.2 输入 vs 输出

| | 输入 | 输出 |
|------|------|------|
| 方向 | 外部信息→计算机二进制数据 | 计算机二进制数据→人类可识别形式 |
| 举例 | 键盘、鼠标、扫描仪、麦克风、光学字符阅读机 | 显示器、打印机、音箱、绘图仪 |

### 7.3 PCI vs PCI-E 总线

| | PCI | PCI-E (PCI Express) |
|------|-----|------|
| 传输方式 | **并行**，共享带宽 | **串行**，点对点独占带宽 |
| 带宽 | 132MB/s（32位/33MHz） | 3.0 X16达16GB/s |
| 适用 | 早期低速设备（声卡、网卡） | 高速设备（**显卡**、SSD） |
| 兼容性 | 固定位宽 | 向下兼容，支持X1/X4/X16 |

> 🎮 **显卡用PCI-E：带宽需求大（4K游戏/3D建模），独占带宽无竞争**

### 7.4 USB特点

| 特点 | 说明 |
|------|------|
| 高速 | USB 3.0=5Gbps, 3.2=20Gbps |
| **热插拔** | 通电可插拔，无需重启 |
| 多设备 | 单接口最多127个设备（集线器扩展） |
| 独立供电 | 5V/500mA，为U盘/手机供电 |
| 向下兼容 | 新版本兼容旧设备 |

> ⚠️ 串行接口的数据传输率**并非总是**高于并行接口（早期并行IDE 133MB/s > USB 1.1 12Mbps，后来串行才超越）

### 7.5 I/O优先级查询步骤

1. **初始化**：设优先级，清状态寄存器
2. **轮询**：从高到低读取各设备状态寄存器
3. **处理**：若就绪→发控制命令→完成I/O操作→复位状态
4. **循环**：继续查下一级，无就绪则返回原任务，间隔后再查

## 九、技术指标与选购

### 9.1 主要指标一览

| 部件 | 指标 | 影响 |
|------|------|------|
| **CPU** | 核心数 | 越多→多任务越强 |
| | 主频 | 越高→单核越快（3GHz>2GHz） |
| | 制程 | 越小→功耗低、发热少（7nm>14nm） |
| **内存** | 容量 | 越大→同时运行程序越多（16GB>8GB） |
| | 频率 | 越高→数据传输越快（DDR5-5600>4800） |
| **外存** | 读写速度 | SSD(3000MB/s) > HDD(200MB/s) |
| | 容量 | 越大→存储越多 |
| **显卡** | 显存容量 | 越大→支持更高分辨率游戏/设计 |
| | 显存位宽 | 越宽→图形传输越快（128bit>64bit） |

### 9.2 寻址计算

```
16GB内存，字长64位 → 寻址需要多少位？

16GB = 16 × 1024³ = 2³⁴ 字节
每字 = 64位 ÷ 8 = 8 字节
总字数 = 2³⁴ ÷ 8 = 2³¹ 字
寻址位数 = log₂(2³¹) = 31 位
```

### 9.3 选购原则

- **兼容性**：CPU插槽匹配主板、内存DDR类型匹配
- **避免瓶颈**：高端CPU别配低端硬盘
- **按需配置**：办公≠游戏需求（显卡是关键分水岭）
- **品牌可靠**：CPU选Intel/AMD，硬盘选希捷/西数

## 十、高频易错速查

| 陷阱 | 正确答案 |
|------|----------|
| CPU由运算器+控制器+存储器组成？ | ❌ CPU = 运算器+控制器（**不含存储器**） |
| 主存储器 = RAM + 磁盘？ | ❌ 主存 = **RAM + ROM**（磁盘是外存） |
| 断电后RAM信息保留？ | ❌ RAM = **易失性**，断电丢失 |
| 静态RAM断电后信息不丢失？ | ❌ SRAM只是无需刷新，**断电照样丢**（仍属易失性） |
| 静态RAM集成度比动态RAM高？ | ❌ 静态RAM集成度**低**（晶体管多），动态RAM集成度高 |
| Cache速度远慢于CPU？ | ❌ Cache速度**接近CPU**，目的是减少CPU等待 |
| EPROM = 可编程ROM？ | ❌ EPROM = **可擦除**可编程ROM（Erasable PROM） |
| 扫描仪是输出设备？ | ❌ 扫描仪是**输入**设备 |
| 串行接口数据传输率总是高于并行？ | ❌ 早期并行(IDE 133MB/s) > 早期串行(USB 1.1 12Mbps) |
| 外存属于主机组成部分？ | ❌ 外存属于**外部设备（外设）** |
| CPU可以直接访问外存？ | ❌ 必须通过**内存**中转 |
| 存储器容量越大速度越慢？ | ❌ 无绝对反比关系（SSD 4TB照样快于小HDD） |
| ALU运算不需要时钟信号？ | ❌ ALU在CPU中操作**需要**时钟信号来同步 |
| 栈遵循FIFO原则？ | ❌ 栈=LIFO（后进先出）；队列=FIFO（先进先出） |
| 内存比外存慢？ | ❌ 内存比外存**快**（DRAM ns级 vs HDD ms级） |

### 大题参考答案

**16. 多级存储系统**

三级组成：
- **Cache（SRAM）**：最快(1-10ns)、最小(MB级)、最贵，匹配CPU速度
- **主存（RAM+ROM）**：居中(10-100ns)、GB级，存放当前运行程序
- **外存（HDD/SSD）**：最慢(ms级)、TB级、最便宜，长期大容量存储

采用原因：**平衡速度-容量-成本**。单用一种存储器无法同时满足三个需求——全用SRAM太贵，全用HDD太慢。三级搭配以较低成本实现接近CPU速度的存储性能。

**17. SRAM vs DRAM**

| | SRAM | DRAM |
|------|------|------|
| 原理 | 双稳态触发器 | MOS管电容 |
| 刷新 | 不需要 | 需要(~64ms) |
| 速度 | 快(1-10ns) | 慢(10-100ns) |
| 集成度 | 低 | 高 |
| 成本 | 高 | 低 |

Cache用SRAM：速度快，匹配CPU节奏。主存用DRAM：集成度高、成本低，可在合理价格下提供大容量。

**18. PROM/EPROM/EEPROM**

| | PROM | EPROM | EEPROM |
|------|------|------|--------|
| 编程 | 一次性 | 可多次 | 可多次 |
| 擦除 | 不可擦 | 紫外线整体擦 | **电擦除，可局部** |
| 应用 | 老式家电固件 | 早期主板BIOS | 主板CMOS、U盘、SD卡 |

**19. Cache原理**

Cache是CPU与主存间的高速缓冲存储器，基于**程序访问局部性**原理：CPU一段时间内只频繁访问主存的局部区域。

工作流程：CPU先查Cache→命中直接读→未命中从主存取，同时写入Cache供后续访问。

提高性能方式：减少CPU等待主存的时间（Cache速度接近CPU，远快于主存），让CPU大多数时候能从Cache取数据，避免频繁访问慢速主存。

**20. 内存 vs 外存**

| | 内存 | 外存 |
|------|------|------|
| 速度 | 快(ns级) | 慢(ms级) |
| 易失性 | RAM断电丢失 | 断电保留 |
| 容量 | 小(GB级) | 大(TB级) |
| 用途 | 运行当前程序 | 长期存储 |

外存属于外部设备的原因：CPU不能直接访问外存（必须通过内存中转），外存通过I/O接口与系统连接，在硬件结构上是"外围"——不像主存那样挂在CPU的系统总线上直接交互。从多级存储角度看，辅存(外存)位于最外层，属于外设范畴。
